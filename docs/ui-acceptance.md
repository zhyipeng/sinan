# 插件主面板与拆出手动验收

在项目根目录运行：

```sh
make ui-acceptance
```

当前要求 macOS。建议先从托盘退出日常实例，避免两个实例争用 Command + Space；日常配置和插件不会被修改。

命令构建宿主和客体，在系统临时目录准备独立实例，仅安装「设置」「插件管理」「窗口验收」。启动后直接显示插件管理，找到「窗口验收」，点击 **打开 输入测试**。托盘悬停文字包含「临时验收」，用它区分日常实例。

搜索面板输入「窗口验收」或 `window`，回车进入主面板中的插件页；顶部应有「返回」和「独立 ⌘⇧D」。也可从管理界面打开。

## 点测顺序

| 操作 | 通过标准 |
| --- | --- |
| 搜索并打开输入测试 | 无边框主面板显示插件，顶部操作区约 50 高，不出现第二个普通窗口 |
| 输入中文、选词、回车换行，再输入英文 | 不丢字、不误关闭；组词状态正确 |
| Command + Space 两次 | 插件面板隐藏再显示，文本保留 |
| 点击其他应用后再次呼出 | 失焦隐藏；呼出恢复原页面 |
| 将鼠标移到三块屏幕分别呼出 | 鼠标屏幕横向居中，顶部位于可用区域 20%，包括左侧 DELL U2719D 和 DELL P2723D |
| 在全屏应用上呼出 | 面板可见可输入，不切换到其他桌面 |
| 输入一段文字后按 Command + Shift + D | 变为可拖动、带标题栏的独立窗口，原文字保留 |
| Command + Space 呼出和隐藏 | 搜索面板独立显隐，已拆出窗口保持显示 |
| 搜索同一命令或从管理界面打开 | 聚焦原独立窗口，文本和拖动位置保留，不重建窗口 |
| 最小化独立窗口后搜索打开 | 恢复同一窗口 |
| 关闭独立窗口后重新打开 | 新页面回到主面板，旧文本清空 |
| 点击主面板顶部返回 | 当前插件关闭并回到搜索 |
| 点击主面板顶部独立按钮 | 与拆出快捷键效果一致 |
| 点击页面关闭或独立窗口标题栏关闭，再打开 | 正常回收并可重新打开 |
| 点击模拟卡死，再次确认 | 当前页面被回收，搜索仍可用 |
| 拆出后从插件管理禁用、卸载 | 对应窗口关闭，其他窗口与主面板保持可用 |
| 从临时实例托盘退出 | 宿主、客体退出并清理临时目录 |

设置、插件管理也支持拆出，无需开启第三方 HTML 加载：

1. 搜索「设置」，录入一组新的呼出快捷键但不保存，再按 Command + Shift + D。应出现标题为「设置」的独立工具窗口，待保存草稿仍在。
2. 在独立设置页继续录入、取消、保存快捷键，均应正常。录入过程中 Command + Shift + D 应被录入控件接收，不误拆出；拆出后 Escape 可取消录入。
3. 用实际生效的呼出热键显隐搜索面板，设置窗口应保持显示；切换应用后也不自动隐藏。
4. 在新主面板打开「插件管理」，输入一个测试目录但不点检查，按拆出按钮。输入应保留，设置窗口不受影响。
5. 拖动、调整大小、关闭任一独立窗口，另一个窗口和搜索面板应继续可用。关闭设置窗口后重新打开应是新页面，不保留未保存草稿。
6. 从主面板管理入口禁用或卸载设置插件，已有独立设置窗口应关闭；恢复启用后仍可重新打开。仅在临时实例进行这些操作。

页面不持久保存输入；只在关闭再打开后检查输入清空。「模拟卡死」会丢失当前输入。真实输入法、键盘快捷键、三屏和全屏需要人工点测，浏览器模拟不能替代。

## 自动检查与记录

```sh
make test
make ui-probe
```

自动检查覆盖会话、并发、故障回收、固定原生探测及 AppKit 事件队列派发；原生外部客体测试使用 `-count=1` 禁用测试结果缓存。它们不能替代上表的人工操作。请记录失败步骤、macOS 版本、显示器与全屏状态、输入法，以及是否可以重新打开窗口；无需发送实际输入的私人文本。

正常托盘退出及终端 Ctrl+C / SIGTERM 均走宿主关闭回调，先回收客体再删除临时环境；准备失败也清理。SIGKILL 或系统异常终止无法保证回调执行，可能留下 `sinan-ui-acceptance-*` 临时目录。此命令不调用日常开发插件准备脚本，不访问日常插件根目录，也不恢复之前移除的 demo 插件。

## 呼出事件串窗回归

拆出设置页或插件管理，保留未保存的输入。连续呼出/隐藏主搜索框，再搜索和打开其他界面：独立页应保持原界面和草稿；新主窗口应仍能正常搜索与拆出。该项修复覆盖 launcher:show 重置串窗和 view:detached 角色误广播。

浏览器自动回归（另一个终端先运行前端 dev 服务）：

```sh
npm --prefix apps/desktop/frontend run dev
npm --prefix apps/desktop/frontend run test:windows
```
