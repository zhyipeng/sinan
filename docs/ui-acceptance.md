# 独立窗口手动验收

在项目根目录运行：

```sh
make ui-acceptance
```

当前要求 macOS。建议先从托盘退出日常实例，避免两个实例争用 Command + Space；日常配置和插件不会被修改。

命令构建宿主和客体，在系统临时目录准备独立实例，仅安装「设置」「插件管理」「窗口验收」。启动后直接显示插件管理，找到「窗口验收」，点击 **打开 输入测试**。托盘悬停文字包含「临时验收」，用它区分日常实例。

新增搜索入口：先关闭已打开的验收窗口，再呼出搜索面板，输入「窗口验收」或 `window`，回车后应直接出现独立窗口，搜索面板隐藏；不会出现命令表单。管理界面的打开按钮仍保留。同一窗口重复打开会聚焦已有窗口，不创建第二个窗口；输入内容和拖动后的位置应保留。

## 点测顺序

| 操作 | 通过标准 |
| --- | --- |
| 打开 输入测试 | 出现独立「窗口验收」页面，输入区可输入 |
| 输入中文、选词、回车换行，再输入英文 | 不丢字、不误关闭；组词期间显示「正在组词」，完成后恢复输入状态 |
| 点击清空 | 文本清空，字符计数归零，输入区重新获得焦点 |
| 用 Command + Space 呼出/隐藏搜索 | 搜索面板工作正常，独立窗口仍可继续输入 |
| 切到全屏应用，再从验收实例呼出并打开窗口 | 窗口可见、可操作，不被留在不可见的 Space |
| 点击页面的关闭窗口，然后从插件管理重新打开 | 正常关闭，随后可再次打开 |
| 点击原生标题栏关闭按钮，然后重新打开 | 同样正常关闭与回收 |
| 点击模拟卡死，再次点击确认 | 页面在响应超时后被回收，宿主仍能呼出并重新打开 输入测试 |
| 打开窗口后，在插件管理禁用窗口验收，再启用 | 已有窗口关闭；启用后可重新打开 |
| 最后打开窗口，再卸载窗口验收 | 窗口关闭，插件从当前临时实例移除 |
| 从临时实例托盘退出 | 宿主和客体退出，临时目录清理 |

搜索面板每次呼出会返回搜索页；需要重新打开窗口时，点击管理插件入口。卸载测试后，再次运行同一命令会建立全新的验收实例。

只在窗口关闭并重新打开后检查输入清空；页面不持久保存输入内容。「模拟卡死」会使当前页面的未保存输入丢失，两次点击是为了避免误触。浏览器预览不会执行死循环，也不能验证原生输入法、窗口关闭和全屏行为。

## 聚焦、标题与多屏补测

- 窗口标题应为「窗口验收 · 输入测试」。输入一段文字，回到搜索再次打开，或从管理界面打开，应回到同一窗口且文字仍在。
- 将窗口最小化，再次搜索打开，应恢复窗口；把窗口拖到其他位置，再次打开不应重置位置。
- 关闭窗口，将鼠标分别移到三块显示器后重新打开：新窗口应在鼠标所在屏幕的可用区域居中，不被菜单栏或 Dock 遮挡。包括位于主屏左侧的 DELL U2719D 和 DELL P2723D。
- 聚焦后继续中文组词和换行；禁用插件后不得通过重复打开重新显示旧窗口。重新启用后应打开全新窗口。

## 自动检查与记录

```sh
make test
make ui-probe
```

自动检查覆盖会话、并发、故障回收、固定原生探测及 AppKit 事件队列派发；原生外部客体测试使用 `-count=1` 禁用测试结果缓存。它们不能替代上表的人工操作。请记录失败步骤、macOS 版本、显示器与全屏状态、输入法，以及是否可以重新打开窗口；无需发送实际输入的私人文本。

正常托盘退出及终端 Ctrl+C / SIGTERM 均走宿主关闭回调，先回收客体再删除临时环境；准备失败也清理。SIGKILL 或系统异常终止无法保证回调执行，可能留下 `sinan-ui-acceptance-*` 临时目录。此命令不调用日常开发插件准备脚本，不访问日常插件根目录，也不恢复之前移除的 demo 插件。
