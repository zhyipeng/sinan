# ADR 0063：core 加密私有存储与 LLM 翻译

日期：2026-11-14。状态：已实现，无界面验证记录见下文；实机 UI 与真实服务未验收。

LLM 配置与请求承载已由 [ADR 0064](0064-shared-llm-capability.md) 更新为全局共享能力；本 ADR 的通用加密存储继续有效。

## 背景与职责

用户要求翻译增加可自行命名的多套 OpenAI 兼容配置，并明确改为由 core 实现加密存储，不使用系统钥匙串。用户选择自动解锁：主密钥存于本地用户目录，接受同时取得主密钥与密文即可解密的边界。

core 仅提供通用加密文档机制。配置编辑、默认配置、引擎选择、API URL 校验、翻译提示词及 HTTP 请求仍在独立官方翻译插件；不将 LLM 业务搬入内核。

## 加密存储

- 每个插件一个私有加密 JSON 文档，明文上限 20 KiB；随机 256 位主密钥存于插件安装根目录的 `.sinan-state/keys/plugin-data.key`，密文位于 `.sinan-state/encrypted-data/<plugin-id>.json`。
- 使用 Go 标准库 AES-256-GCM，每次写入生成独立随机 nonce，以格式版本、插件 ID 和文档 revision 作为附加认证数据，阻止密文跨命名空间/版本替换。外层保留 revision，复用原有 CAS、大小限制、临时文件同步与替换机制；主密钥初始化以排他创建写入，不覆盖已有文件。
- 首次写入才生成主密钥；已有密文但密钥丢失、长度不符、文件/目录为链接或认证失败时保留原文件并报错，不自动生成替代密钥，不降级明文。
- macOS/Linux 为主密钥文件设置 0600、目录 0700；Windows 对主密钥文件与加密存储目录设置当前账户专用的受保护 DACL。使用既有安装根目录租约约束多宿主并发，不增加另一套锁文件协议。
- 这是磁盘静态加密，不是 OS 沙箱或内存加密。获得同账户权限、主密钥及密文的人可解密；不防进程调试、管理员接管、文件回滚或历史备份恢复。迁移/备份须配套保管主密钥与密文；没有密码找回机制。

## 页面协议与生命周期

UI Bridge 2 新增 `storage.encrypted.get` / `storage.encrypted.put`，请求结构分别与既有 `storage.get` / `storage.put` 一致，返回仍为 `{revision,value}`。页面须显式声明 `storage.encrypted`，普通 `storage` 不授予加密访问。视图权限枚举、清单校验、JSON Schema、TypeScript 协议和 UI SDK 同步。

身份仅来自当前页面会话，页面不能提供插件 ID、路径或密钥；沿用 ready、实例/指纹、撤销、每会话在途数量、每分钟频率与 500 毫秒调用预算。解密后的配置仅返回获授权的所属插件页面，页面通过已声明的同插件命令将所选配置交给其原生后端使用。API Key 不回填 DOM 表单，不写入普通文档、URL、日志或使用历史；这不意味着页面或原生插件无法访问其自己的凭据。

插件中心 0.9.1 仅显示加密文档元数据，使用带数据类别前缀的清理指纹区别普通/加密同名文档。清空仍须匹配当前文件指纹并撤销插件页面，避免旧页面重新写入；不改变正常卸载保留用户数据的规则。删除 LLM 配置重写加密文档，不承诺擦除磁盘历史或备份。

## 官方翻译插件 0.2.0

保留已有免费引擎、复制与 0.2 内容匹配权重，在其后增加 LLM 引擎。插件页面支持至多 16 套配置（总量受 20 KiB 配额约束）：名称、API 地址、模型、可选 API Key，以及默认 LLM 配置。命名不重复，修改地址时不静默复用原 Key；空 Key 编辑表示保留，可显式清除。

按 OpenAI Chat Completions 的兼容格式使用 `POST .../chat/completions`、`model`、`messages`、非流式文本响应和可选 Bearer 认证；仅使用配置的服务，不自动切换免费服务。HTTPS 可用于远程服务；HTTP 仅允许 localhost 或 loopback IP。拒绝用户信息、查询参数、片段与所有重定向，不回显错误响应、请求头或原始网络错误。认证失败、限流、空响应、非兼容响应和超时均提供固定错误提示。

LLM 任务总预算 45 秒，HTTP 预算 40 秒，沿用启动/轮询/取消机制；免费引擎仍为 12 秒任务。请求发送仅发生于实际翻译，配置保存只做本地校验。来源及目标语言沿用现有规则。提示词仅要求翻译，原文作为独立 user 消息；不运行模型返回的 HTML、代码或工具调用。

接口格式参考[OpenAI 官方文档](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。第三方兼容服务的模型能力及稳定性需分别核对，不等同于 OpenAI 官方服务。

## 跨仓库与兼容

旧宿主会拒绝 `storage.encrypted`，因此插件 0.2.0 须配套支持本 ADR 的宿主。后端 API 1 与桥版本 2 不变，不以相同开发版本号替代能力核对。SDK 快照记录来源提交、文件哈希及显式增量补丁，补丁未并入来源提交时不声称来源提交已含新接口。

已核对 sinan、sinan-official-plugins 和 sinan-plugin-registry：前两者分别维护通用机制和业务；目录无翻译正式发布记录，本轮不登记未上传的资产。三平台均使用共享 Go 加密与业务代码，Windows 的文件访问控制为独立适配；不依赖钥匙串、Credential Manager、D-Bus、X11 或 Wayland 执行存储或翻译。

## 验证边界

离线测试覆盖密文无明文、跨重启解密、随机 nonce、篡改/跨插件/版本替换拒绝、密钥丢失不再生、CAS、配额、会话权限及撤销、加密数据管理清理；LLM 采用 HTTP 夹具验证协议、语言回退、认证、拒绝重定向、取消和错误脱敏，DOM 夹具验证多配置增删改、默认配置、Key 不回显、地址变更保护和保存冲突。构建、跨目标编译和真实平台执行分别记录，不触发真实 WebView 或系统剪贴板。

本轮本机记录：`node scripts/desktop.mjs test`、官方插件 `npm test`、新增 11 项翻译页面无界面测试、存储与内核竞态回归、相关包 `go vet` 及 macOS arm64 宿主构建均通过。存储/内核测试可执行文件和翻译后端各完成三 OS × 两架构交叉编译，六个插件 ZIP 的入口、版本、权限、SHA-256 校验通过；SDK 文件哈希与来源补丁重放通过。临时安装目录完成包检查、安装、LLM 默认引擎保存/读取及原生进程本地配置校验。Windows/Linux 未运行测试二进制；未启动真实桌面/WebView、未使用真实 API Key 或调用真实 LLM，也未发布资产。
