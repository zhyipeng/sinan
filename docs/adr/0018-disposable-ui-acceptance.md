# ADR 0018：独立临时 UI 验收环境

- 状态：验收环境已实施；人工交互结果待记录
- 日期：2026-11-05

## 原因

现有三个日常系统插件均无 HTML 视图，无法直接手动验证 ADR 0017 的普通窗口入口。需要提供可点测页面，同时遵守用户移除 demo 插件的要求，不把测试包安装回日常实例。

## 决策

- 新增显式开发命令 `make ui-acceptance`，构建宿主后以 `-ui-acceptance` 启动。该模式自行生成系统临时根目录，不允许同时传入 `-plugins` 或 `-ui-probe`，不读取日常配置、插件目录，也不调用 prepare-dev。
- 临时实例仅安装源码中的声明式设置和管理插件，以及内嵌 `dev.ui-acceptance`。验收页仍遵循 Manifest、指纹、声明视图、空权限和独立客体路径，不增加特权桥接或任意脚本注入。
- 页面保持项目现有配色、系统字体和简洁布局，只保留输入区、组词/字符状态与操作按钮。模拟卡死须二次点击，真实原生页面执行死循环来验证既有响应预算；浏览器预览拒绝执行死循环。
- 普通窗口默认内容尺寸改为 640 × 480，探测模式保持原尺寸。只改变内部默认值，不增加包自定义窗口配置契约。
- 以入口 URL 标记首次打开插件管理；此标记不授予权限，后端独立窗口开关和声明检查仍是最终边界。验收实例使用不同应用名与托盘提示，快捷键设置只落在临时根目录。
- 清理注册到 Wails OnShutdown，顺序为取消/回收客体、关闭内核、删除临时根目录。保留 defer 处理初始化失败，但不能只依赖它：实测 macOS 原生退出没有回到 Go defer。
- 不保证 SIGKILL、系统崩溃等不可执行关闭回调的场景自动清理；不静默扫描或删除其他实例留下的目录。

## 验证

- Go 竞态测试验证只准备三个指定插件、资源可通过声明会话读取、源包不变、重复清理安全、会话撤销、目录移除及准备失败清理。
- 浏览器检查中文/英文多行输入、组词事件显示、清空和预览卡死防护；管理回归增加首次直接进入插件管理。模拟 CompositionEvent 不等同真实输入法验收。
- 真实桌面以专属 TMPDIR 启动，确认验收包准备、进程持续运行，分别发送 SIGINT / SIGTERM，验证退出码成功且临时验收根目录已移除；初次检查发现仅用 defer 不能清理，接入关闭回调后复测通过。
