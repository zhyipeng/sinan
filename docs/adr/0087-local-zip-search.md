# ADR 0087 主输入框安装本地 ZIP 插件

日期 2026-11-18

## 决策

插件中心通过宿主注册的可信文本匹配入口，处理主输入框键入的查询和显式粘贴的文本。只匹配当前系统的绝对路径，文件名需采用 `<id>-<version>-<os>-<arch>.zip`。路径可包含空格及成对的外层引号。搜索阶段只识别路径和名称，选中「安装插件」时才访问文件。

结果指向现有插件中心命令。选中后展开本地安装区，自动发起既有的检查与应用流程，并在插件中心显示结果。安装继续使用已有的解包预算、指纹复核和原生信任规则。

## 影响

搜索协调器负责合并结果及取消过时查询。匹配规则和安装交互由插件中心实现，新增的搜索结果及安装流程通过可信 Shell 与宿主传递归档路径。公开协议、第三方桥、权限、SDK 和发行格式沿用现有接口。
