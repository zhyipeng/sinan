# ADR 0089：脚本执行结果与桌面通知

日期：2026-11-18。状态：已实现，待原生通知和桌面界面实机验收。

脚本插件持久化每个脚本的搜索与输出开关。旧记录和新脚本默认显示在全局搜索，执行时默认不打开输出页。关闭搜索仅影响全局 Provider。输出页沿用隔离视图和选中条目的不透明 ID。脚本插件在执行前复核当前设置；旧结果不能启动已隐藏或更换执行模式的脚本。

脚本在插件进程内合并捕获标准输出和标准错误，输出页通过私有命令按运行 ID 查询进度与退出状态。后台执行结束后向宿主提交纯文本通知。超过通知正文预算时提供临时日志路径，路径过长时返回系统临时目录中的文件名。输出页和管理页的「结果」也可查看日志位置。页面预览最多 16 KiB 原始数据，完整输出写入日志，写入失败会标注输出不完整。临时日志在类 Unix 系统以 0600 创建，Windows 使用调用用户的临时目录和系统 ACL；保留的日志随系统临时目录清理。通知与输出采集取决于宿主及插件进程仍在运行。

宿主增加原生进程权限 `notifications.send` 和反向 RPC，独立于 Wails Bridge。权限取自已安装并信任的进程清单。宿主限制标题 160 字节、正文 512 字节和单进程每分钟 24 次，拒绝附加字段、任意附件或动作。通知采用 Wails 3.0.0 Notifications，日志路径在正文中作为文字显示。平台通知不可用、被拒绝或超时不影响脚本退出结果，管理页保留结果。

macOS 需要有效的、已签名的应用包与系统授权，第一次后台通知时请求授权。Windows 由 Wails 注册 Toast 应用标识和激活器。Linux 使用会话 D-Bus 和桌面通知守护程序，X11 与 Wayland 都依赖所在桌面的通知服务。宿主可在通知服务启动失败时继续运行。原生发送不持有宿主运行时锁，并使用有界等待与单个发送槽。

旧宿主拒绝新清单权限。Go/TypeScript 协议、Schema、SDK 和官方仓库快照同步维护。插件商店格式不受影响，配套宿主和插件未发行。
