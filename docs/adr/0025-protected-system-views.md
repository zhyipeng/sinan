# ADR 0025：设置与插件管理禁止禁用、卸载

- 日期：2026-11-09
- 状态：采用
- 依据：用户要求保护设置与插件管理
- 覆盖：ADR 0010 / 0011 中允许正常卸载、禁用管理插件的交互；外部故障恢复继续保留

## 决策

内核以固定 ID 保护 system.settings 与 system.plugin-manager，拒绝卸载及禁用请求，在文件移除、会话撤销和策略持久化之前返回错误。桌面、CLI 和其他内核调用入口共享该限制。启用、重载、升级以及其他插件的正常管理继续可用。

PluginInfo 增加只读 protected 元数据，管理插件据此隐藏卸载与启停用按钮；保护不是 manifest 字段，插件无法自行取消宿主策略。

加载格式有效的历史禁用列表时，忽略这两个 ID，其他禁用记录保留；不自动改写源配置。格式错误及损坏的配置继续沿用既有默认拒绝和恢复规则，不以系统插件保护绕过配置校验。该策略不自动重装已经丢失的包，也不保证外部删除、手改文件或包损坏不会影响可用性。

## 验证

内核回归覆盖两类禁止操作、拒绝后文件与策略不变、允许启用、普通插件仍可禁用卸载、历史禁用记录在重启后被忽略且源配置保持不变。浏览器回归检查四个禁止操作入口均不存在，普通管理操作保留；旧的自禁用、卸载恢复用例改为模拟外部故障，不再通过被禁止的 UI 操作构造状态。
