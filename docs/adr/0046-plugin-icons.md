# ADR 0046：可选插件图标

日期：2026-11-12。状态：已实现，无真实 UI 验收。

## 决策与原因

插件通过 Manifest 可选 `icon` 声明包内相对路径，支持 SVG、PNG、JPEG。宿主读取后输出图片 data URL，插件管理、搜索结果、可信及同窗口 HTML 插件页头共用图标组件；搜索结果已有的应用/项目图标优先。未声明、资源缺失或加载失败均显示插件名首个 Unicode 字符。保留现有 API 1，无图标的旧包继续有效；当前严格解析器的旧宿主不能读取新增字段，新增图标的包需要升级宿主。

内置插件与官方 JSON 工具提供同一网格、线宽及冷色系的 SVG。图标随插件包复制，开发包和官方构建同步包含资源。

## 边界与影响

路径最长 256 字符，只允许包内相对路径，使用 os.Root 阻止通过符号链接越界。图片最多 64 KiB，位图宽高各不超过 1024；SVG 限制为静态基础几何元素、有限属性、最多 512 元素和有界嵌套，不允许脚本、样式、外部资源、实体、动画或链接。资源无效不会阻止插件加载。图标以 img 加载，不将 SVG 插入可信 DOM，也不新增页面桥权限或沙箱承诺。

商店目录增加可选 `icon` 图片 data URL，复用宿主图片校验，无图标时优先采用已安装插件图标，再由 UI 显示首字。目录内嵌图片使未安装插件无需额外网络请求即可显示图标。登记官方 JSON 工具图标，没有生成发行版本或发布远端。

## 验证

增加图标解析、大小预算、外部引用拒绝、相对路径及符号链接越界回归。执行无界面测试、前端类型检查及构建、官方插件构建和目录资料校验；未启动桌面或浏览器交互验证。
