# ADR 0008：可配置呼出快捷键

- 状态：已实施
- 日期：2026-11-05

## 原因

用户要求在设置中修改并录入快捷键。全局注册影响 Shell 的恢复能力，不能交给普通插件进程直接管理；界面仍属于 `system.settings`。

## 决策

- 设置插件增加组合键录入、恢复默认、显式保存。macOS 默认 `Cmd+Space`，其他平台默认 `Ctrl+Space`。使用物理按键 code 识别字母和数字，避免 Option 等修饰键改变字符。
- 宿主校验并规范化组合键，只接受主修饰键与标准按键，允许叠加 Shift，保留 Escape 用于隐藏。首版不接受标点、媒体键及单修饰键。
- 宿主通过 Wails 全局快捷键 API 注册，应用启动完成后才实际尝试注册并返回错误。保存先注册新组合，成功后释放原组合，再持久化。新注册失败不动原组合；存储失败撤销新组合并尝试恢复原组合。系统释放或恢复失败时明确报错，保留托盘恢复入口。
- 配置沿用核心 JSON 设置存储、原子写入和 revision 比较。宿主用保留的 `$launcher` 命名空间保存 `shortcut`；此命名空间不是合法插件 ID，插件设置 API 无法读取或写入。文件版本仍为 1，不修改插件协议或增加第三方插件权限。
- 录入时，宿主把当前呼出热键改为向主窗口发送 `shortcut:recorded`，避免隐藏设置。仅在窗口可见且聚焦时允许开始；失焦、组件卸载、取消或 30 秒超时后结束。其他候选组合由设置组件捕获；系统截获的其他组合可能无法录入。
- `shortcut:changed` 更新设置状态、Shell 错误与托盘提示。操作系统回调异步进入控制器，避免 UI 线程与同步原生注册之间发生锁等待。

## 影响及验证边界

快捷键修改不需要重启，重启后读取已保存值。设置组件仍随宿主构建，升级插件包不等同于动态替换可信组件代码。

控制器测试覆盖规范化、切换、注册冲突、原注册释放失败、持久化失败回退、过期 revision 和录入分流；内核测试覆盖持久化及插件命名空间隔离。浏览器回归覆盖按键录入、无效组合、冲突提示、保存、重新进入、取消、当前热键录入和恢复默认。操作系统保留热键行为依赖平台；Windows/Linux 尚未实机验证。

本轮 macOS 原生界面自动操作遇到 ScreenCaptureKit 捕获错误，未完成真实全局热键切换的自动验证，仍需实机试用确认。
