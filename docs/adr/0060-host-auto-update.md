# ADR 0060：桌面宿主自动检查与确认安装更新

日期：2026-11-14。状态：已实现，本地无界面与发行归档检查通过；真实退出、替换与重启待验收。

## 决策

用户在要求提交自动发布改动后，明确要求暂不推送并继续实现自动更新，选择「启动后自动检查，发现新版后提示，由用户点击下载并安装」。

稳定版本检查策略、状态和更新界面属于 `system.settings`，界面追加在已有设置之后；搜索栏只承载该插件提供的「有更新」提示组件。宿主只适配可信 Wails 调用和应用生命周期。`internal/hostupdate` 提供目录识别、有预算的解压、助手交接、替换和回退机制；独立 `sinan-updater` 不加载插件或 WebView。未将插件更新业务移入内核。

正常发行实例启动后三秒检查一次固定仓库 `zhyipeng/sinan` 的 GitHub latest 稳定版。仅接受有效且比当前版本新的 SemVer，精确匹配当前 OS/架构的既有归档名及公开的 `SHA256SUMS.txt`。开发构建、显式插件目录、探测及临时验收实例不自动检查。检查失败不阻断搜索或插件运行；设置页可手动重试。不自动下载，不订阅预发布渠道，不自动提权。

用户点击「下载并重启安装」后，校验下载长度与 SHA-256，在安装目录同级的私有暂存目录解压并检查版本、平台和四个可执行文件；macOS 额外检查完整 Bundle 签名。拒绝链接、路径越界、Windows 保留文件名、重复路径、大小写碰撞和超预算内容。归档生成禁止 macOS AppleDouble 扩展属性旁路文件，保证各平台统一使用明确根目录。

当前版本的助手被复制到用户缓存，确认计划可用后才允许退出宿主。助手等待旧进程退出，通过同卷重命名保留完整旧目录并替换新版；新版收到私有更新会话，在 ApplicationStarted 后写回版本和路径绑定的就绪回执。30 秒内没有回执时，终止启动中的新进程、尝试恢复旧目录并重启旧版。此回执仅证明应用到达启动事件，不代替功能或真实 UI 验收。

## 平台和信任边界

macOS 更新整个 `.app`；Windows/Linux 更新整个便携目录。Unix 等待父进程退出，Windows 使用进程句柄等待并隐藏助手控制台；没有通过 sh、PowerShell、cmd.exe 执行替换。应用目录的父目录必须可写，Windows 文件占用/杀毒可能阻止替换，此时重试并保留旧目录。不会修改系统用户配置目录的插件、配置和数据，已有内置插件不会因宿主更新自动覆盖。

更新源固定为官方 GitHub HTTPS API 与发行资产域名，不读取本机 GitHub 凭据，不接收前端传入的 URL、版本、安装路径或启动参数。插件中心的自定义镜像配置不用于宿主可执行文件更新。错误状态不输出临时签名 URL 或原始文件系统路径。

当前没有独立发布者签名清单；SHA-256 与归档同源，信任依赖 GitHub 仓库发布权限和 HTTPS。macOS 仍仅 ad-hoc 签名，无 Developer ID 公证；Windows 无 Authenticode。该机制不是 OS 沙箱，也不绕过 Gatekeeper 或系统权限策略。

助手计划只属于当前安装过程，不是公共插件协议。未新增插件权限或第三方桥能力，sinan-official-plugins 和 sinan-plugin-registry 无需联动修改。

## 保留限制

- 完整旧目录保留在 `.sinan-update-*/previous` 中，暂不自动清理；确认新版可用后可手动移除整个对应暂存目录。
- 普通 I/O 错误与就绪失败有回退处理；断电、强制杀死更新助手或磁盘故障不是完整事务恢复保证。若替换中断，可从相邻暂存目录的 `previous` 手动恢复。
- 应用因更新退出后，助手不能取得主窗口；回退/成功状态写入用户缓存供下次设置页读取。助手自身不能启动、目录不可写或签名/摘要检查失败时，不主动退出当前宿主。
- 自动更新入口需要先手动安装包含该机制的完整发行版；不为历史无助手的构建添加远程执行后门。

验证范围与使用方式见[自动更新](../auto-update.md)。

## 本轮验证

macOS arm64 全量无界面回归、更新包/版本策略竞态测试、静态检查、前端构建、发行打包及真实归档受限解压和 Bundle 签名检查通过。Windows amd64/arm64 的桌面及更新相关包已交叉编译；Linux amd64/arm64 的更新机制、服务和助手在关闭 CGO 下交叉编译，未据此验证 Linux 桌面。Actions 及发布脚本静态/单元检查通过。未推送、未触发远端发布，未执行真实桌面退出替换或重启。
