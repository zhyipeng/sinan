# ADR 0078：截图输出与延迟呈现

日期：2026-11-17。状态：已实现，未发布；真实桌面验收未执行。本文更新 ADR 0076 的显示时机和 ADR 0075 的固定目录保存策略。

## 原因

截图命令返回与页面完成 PNG 读取、解码是两个阶段。原先 window.execute 返回时自动恢复窗口，即使后续读取、解码失败，也已打开后处理。隐藏视图未启动的超时恢复同样会显示空编辑器。用户还要求复制成功后隐藏主窗口，以及通过 Wails 原生对话框保存 PNG。

## 决策

业务仍在独立截图插件。增加通用会话能力 ui.image-output.v1，API 1、UI Bridge 2 保持不变；不能用相同开发版本号代替能力检查。旧宿主不具备新能力时插件明确拒绝初始化。

- CommandResult.keepHidden 可要求 window.execute 成功后保持隐藏；dismiss 仍优先负责取消和无图时的会话清理。截图插件仅在有效 PNG 时返回 keepHidden，待页面读取、解码及编辑器载入成功，再显式请求显示。读取或解码失败请求隐藏，未启动的隐藏页面超时清理，不自动显示空编辑器。隐藏启动在执行前取消也保持关闭。
- 新增视图权限 window.show、window.hide；SDK showWindow/hideWindow 仅作用于当前活跃会话绑定的窗口。隐藏同时覆盖主窗口；不会操作其他插件的拆出窗口。原生复制成功之后才调用 hideWindow，失败保留页面与重试能力。按钮与 Command/Ctrl+C 共用流程；文字输入、选中文本、输入法组合期间保留原复制行为。
- 新增视图权限 file.savePNG 与 SDK savePNG(commandId,input)。命令必须在本视图 commands 中声明，宿主通过 ExecuteViewCommand 重新验证同实例、包指纹和会话。input 是 32 字符不含冒号的不透明上传标识；宿主向导出命令发送 `<input>:<offset>`，CommandResult.text 返回 JSON `{size,data}`，data 是 base64，每块最多 36 KiB。宿主校验响应预算、总量稳定、非空进展、8 MiB 限制、PNG 完整流及 3200 万像素，再调用 Wails SaveFile。
- 保存对话框绑定所属窗口并使用已有 beginDialog 防止失焦隐藏；默认 PNG 文件名与 PNG 过滤器，仅向宿主确认的 .png 路径写入。取消返回 `{saved:false}`，不写文件；成功 `{saved:true}`。页面及插件进程都收不到用户选择的路径。后台 save 命令改为只读导出，取消后可重试，不再自动写系统图片目录。
- file.savePNG 使用 125 秒调用预算，WebView2 等待 127 秒；其他桥调用时限保持原值。保存前和对话框返回后均复核取消及会话状态，撤销后不写文件。Wails 当前接口不提供通用的对话框取消句柄，因此调用超时不会强行关闭已经显示的系统对话框，用户关闭后拒绝写入。

不提供任意路径写入、页面文件系统绑定或完整 Wails Bridge。原生进程仍使用当前用户权限，不构成安全沙箱。CSP、单请求大小、会话并发与现有调用预算不变；大量图片分块仍受已有速率和会话累计请求上限约束。

## 平台与验证边界

三端共享 Go 保存与窗口策略，原生文件选择交由 Wails 的 AppKit、Windows 和 GTK 实现；Linux 桌面仍需既有 GTK3/WebKitGTK 依赖，X11/Wayland 捕获限制不变。PNG 对话框取消、覆盖确认、失焦、快捷键和截图行为需要各平台实机验收；交叉构建不代表运行验收。登记仓库没有新增发布资产。

本轮验证结果在 docs/cross-platform.md 记录。无界面测试覆盖分块、损坏/截断 PNG、取消、声明权限、命令白名单、会话撤销、页面解码失败、复制失败保留窗口与取消保存。未启动真实桌面、WebView、原生保存对话框，未读取真实屏幕或系统剪贴板。
