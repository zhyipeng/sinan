# ADR 0052：插件商店的 GitHub 镜像加速

日期：2026-11-13。状态：首版已实现。

## 背景

插件商店使用公开 GitHub API 获取目录树与 `plugin.json` blob，并以资产 API 下载发行包，全程不带认证。未认证配额为每 IP 每小时 60 次，一次目录刷新消耗 `1 + N` 个请求，容易在共享出口 IP 或频繁刷新时耗尽，界面因此报「GitHub 请求受限」。用户希望增加可选镜像加速：内置若干服务、支持自行配置、URL 按模板拼接、默认官方优先失败回退、可在设置页直接指定。

## 决策与原因

- **新增设置类型**。`contributes.settings` 从只支持 `directory-list` 扩展为 `directory-list`、`select` 与 `text`。`select` 携带 `options`（值/标签）并保存单个值，`text` 保存单行文本并可带 `placeholder`。原因是「在设置页直接指定某镜像」需要下拉选择，而原类型只能录入目录。校验分散在 manifest 声明校验与内核 `SavePluginSettings`：`select` 只接受已声明选项，`text` 限长且拒绝控制字符，`directory-list` 保持原路径校验。
- **配置归属插件中心**。设置项声明于 `system.plugin-manager` 清单（`github-mirror`、`github-mirror-template`），宿主读取后注入目录与下载逻辑。默认空值解析为 `auto`，即官方优先、失败回退内置镜像，不改变首次安装后的默认行为。
- **模板化拼接**。新增 `internal/plugin/ghmirror` 包，模板仅支持 `{url}`（原始完整地址）。要求 HTTPS 且必须含占位符；非法模板被忽略并回退官方。内置服务为 `github.chenc.dev` 与 `gh-proxy.com`，均经实测能代理 `api.github.com`。
- **候选与回退**。`auto`：官方→内置；指定内置：该镜像→官方→其余内置；`custom`：自定义模板→官方→内置；`official`：仅官方。目录读取与资产下载共用该顺序，逐个尝试，任一 200/304 即采用。
- **重定向放宽到同主机**。原目录客户端拒绝一切重定向；实测 `github.chenc.dev` 会把 `https://…` 规范化成 `/https:/…` 并返回 301，故允许与首个请求同主机的 HTTPS 重定向，跨主机仍拒绝。下载重定向除同主机外仍只允许已批准的 GitHub 资产域名。
- **不引入凭据**。镜像仅改变请求出口，不读取本机 GitHub 凭据，也不改变目录内容、资产摘要、ZIP 限制、指纹与信任流程。

## 影响和限制

- 目录客户端与下载器均可通过 `SetConfig` 在每次商店请求时更新配置，设置保存后下次请求即生效，无需重建服务或清空待处理预览。
- 内置镜像是尽力而为、非承诺可用；其自身也可能限流或失效（实测 `gh-proxy.com` 曾返回上游限流 403）。失败即回退官方，不影响原有直连能力。
- 自定义模板仅支持 `{url}`，不提供 `{host}`、`{path}` 等更细占位或请求头改写；复杂镜像适配仍需后续扩展。
- 该能力不改变「尚无独立目录签名、密钥轮换与完整撤销治理」的既有边界，也不能替代签名信任。
