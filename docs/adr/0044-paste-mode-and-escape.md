# ADR 0044：粘贴模式、图片输入与统一 Esc

日期：2026-11-12。状态：已实现，无界面回归验证；真实桌面/浏览器交互未验收。

## 用户要求与交互

主输入框为空时，显式粘贴文本或图片进入粘贴模式。搜索栏左侧用限宽、单行省略的文本块或图片缩略图预览，右侧输入框显示“筛选结果…”，不把大段正文直接放入主输入框。继续沿用宿主主题和结果列表，不引入额外说明区。

粘贴内容固定为本次输入；关键词只在其匹配结果内过滤，按结果标题、来源、插件名和命令关键词匹配，不启动新 Provider 查询，也不将筛选词替换原始内容。纯文本仅走已声明的内容匹配，不因为正文碰巧包含插件名而显示额外命令。

用户确认退格先正常删除筛选关键词；关键词完全为空时再按退格退出粘贴模式。文本长度按 Unicode 码点计算，最多 30 个字符时恢复原文至主输入框，超过 30 个字符则清空；图片退出后清空。主输入框非空时粘贴仍按普通文本输入处理；粘贴模式中再粘贴文本进入筛选字段。

Esc 在主面板的普通输入、粘贴、可信插件、隔离 HTML 插件和恢复页中统一为回到主输入状态并清空输入；已在空的主输入状态时再次 Esc 隐藏。图片异步解码过程中 Esc 也会取消本次进入粘贴模式。独立工具窗口按 Esc 关闭当前工具并显示清空后的主输入窗口，不影响其他独立工具。输入法组合中的 Esc 保留给输入法，避免吞掉候选取消。

## 宿主与协议

- 新增可信 Shell 入口 `StartPasteSearch(sequence, content)`、`ClearPaste(sequence)` 和 `OpenPasteCommand(pluginId, commandId, pasteId)`。它们不进入第三方 Wails Bridge。粘贴事件来自用户显式操作，不增加系统剪贴板监听或读取服务。
- `PasteContent` 恰为一份文本或图片。文本最多 64 KiB；图片由可信前端以原尺寸静态 PNG 规范化，再交宿主验证 Base64、PNG、尺寸及可解码性。源文件最多 16 MiB，规范化 PNG 最多 4 MiB、最多 16,777,216 像素；不承诺动画或原文件元数据保留。图片转换失败或超限保留当前模式并提示错误，不偷偷缩小图片。
- 宿主按当前主窗口保留一份不可变粘贴内容。结果仅携带临时 `pasteId`，不复制大图至结果列表；仅拥有该粘贴状态的窗口能选择它。序列号及清理水位拒绝迟到的粘贴提交；转换、查询取消和前端 generation 拒绝过时结果。宿主同时最多解析一份图片，避免解码并发堆积。
- `inputMatchers` 新增 `{"kind":"image"}`，没有文本正则/JSON/长度参数，只允许桥 2 HTML 视图命令。文本和图片互不匹配。既有 JSON 工具继续只匹配对象与数组，不因支持图片预览而开放图片业务。
- 用户选择结果时再次检查当前插件命令的匹配声明、启用状态与会话，防止清单变化后沿用旧候选。普通主窗口路径在页面提交前再次检查粘贴状态，退出后的迟到打开不能提交。原生命令仍只接收文本。

## 图片隔离与资源预算

`launch.get` / SDK `readLaunch()` 增量返回可选 `image: {url, mimeType, width, height, bytes}`，文本仍为 `input`，二者不混用。图片正文不放进 192 KiB 页面调用返回值，而是固定为该会话的一份不可变 PNG 资源。

地址为同插件 `sinan-plugin:` 下随机生成的临时路径。另一个会话即使知道地址也无法读取；会话撤销立即移除资源。页面可用普通 img 显示，不改变 CSP、不开放任意文件或网络读取，不将图片写入插件目录/草稿或日志。显示图片不授予 storage。主窗口的粘贴暂存由 Esc、退格、替换或正常搜索清理；前端同步撤销缩略图 Blob URL。

固定包快照仍遵守单文件 512 KiB、包资源合计 2 MiB；会话粘贴图片是额外的受限资源，最多 4 MiB，并继续计入既有总计 8 MiB 的会话资源交付预算。helper 私有管道单帧从 1 MiB 提高到 6 MiB，以容纳 4 MiB PNG 的 Base64；公开后端协议和页面请求/返回上限不变。宿主与 helper 须同步重建，旧 helper 不保证支持大图。

## Esc 的可信路径

可信 React 页面在捕获阶段处理 Esc；移除原来无条件隐藏主窗口的 Wails Escape 绑定。隔离 HTML 页面由宿主原生按键监控处理 Esc，走私有原生导航动作，不依赖页面脚本合作，也不向页面增加导航调用能力。helper 承载新增私有 `window-action/reset`，允许附着与独立工具；已成功重置的会话被撤销。返回主输入的动作停止快捷键录入、取消搜索与待提交页面、清除粘贴暂存，然后定向通知对应 Shell；不会广播清空其他独立页面。

## 验证

- 前端无浏览器测试覆盖 30 字符边界、Unicode/多行恢复、结果内筛选、Esc 状态和 Blob URL 清理。
- Go 测试覆盖文本/PNG 验证、格式/大小拒绝、图片仅匹配声明命令、无 Provider 广播、会话图片不可变与隔离、普通打开无图片、撤销访问、helper 附着/独立重置与公开声明校验。
- 按项目约定不启动真实 WebView、桌面窗口或浏览器。视觉与真实剪贴板交互仍需单独验收。


## 搜索生命周期修复

后续用户反馈普通搜索持续停在“搜索中”。排查确认 Wails 在绑定方法返回时取消该次调用上下文，异步查询不能沿用其取消信号。共享搜索入口现通过 `context.WithoutCancel` 保留窗口身份值，再创建独立可取消的查询上下文；新查询替换、显式 CancelSearch、失焦、重置和应用退出仍负责取消，任务结束释放上下文。普通搜索与粘贴搜索共用此路径。

新增不打开窗口的回归，先复现“绑定返回取消导致查询失败”，再验证查询跨越调用返回、窗口身份保留、新查询取消旧查询和旧 effect 取消不误伤新查询。未通过添加等待超时来掩盖结果被取消的问题。
