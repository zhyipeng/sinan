# ADR 0004：可信原生应用检索与通用直接动作

日期：2026-11-04。状态：已实施首版，仅验证 macOS arm64。

## 决策与边界

新增独立进程插件 `system.app-search`。应用发现、索引、匹配、图标读取与启动实现都在 `plugins/system-app-search/`；内核只增加通用命令呈现方式和受限图标数据，不按应用业务分支处理。

本阶段插件按现有 Trusted Native 模型运行，直接使用 Foundation / AppKit 和 `/usr/bin/open`。Manifest 接受 `applications.read`、`applications.launch` 两项用途声明；它们用于记录和校验名称，不代表 Host API 授权检查、目录访问限制或系统沙箱。安装依然需要显式信任整个原生进程。未声明这些用途的其他原生代码同样可能访问系统资源。未来引入受控 Host API 时，平台能力迁移到宿主服务，索引和匹配仍留在插件。此次没有引入反向 RPC 或可信/不可信混用的权限承诺。

这项阶段性取舍用于先验证实用搜索链路，避免在没有系统沙箱的普通原生进程中声称已有权限隔离；不适用于宣称受沙箱保护的第三方插件。

## 应用发现与执行

- 扫描 `/Applications`、`/System/Applications`、`/System/Library/CoreServices/Applications`、`~/Applications`，子目录深度有界、最多 4096 条；不扫描整个磁盘。
- 跳过隐藏目录，不深入 `.app` 的嵌套 helper；仅对 `.app` 入口符号链接读取目标，支持 macOS Safari 的链接布局，按真实路径去重，不递归遍历链接目标。
- 读取 `APPL` Bundle 元数据，兼容二进制 plist。名称依据用户系统语言读取 `InfoPlist.strings`，补充新系统应用的 `InfoPlist.loctable`；英文文件名也参与匹配。loctable 是兼容性回退，未来系统格式变化需再验证。
- 首次查询按需建立内存索引。超过一分钟后的下一次查询重建；另有“刷新应用索引”命令。取消重建保留旧快照，不发布半成品。没有文件监视和磁盘持久化。
- 支持名称精确、前缀、包含、英文词首字母匹配；不含拼音、模糊编辑距离和使用历史排名。相同名称不同路径保留独立条目。
- 只返回稳定的不透明索引 ID 作为启动参数；执行时重新确认条目存在且仍是应用 Bundle，通过参数数组调用 `/usr/bin/open -a <路径>`，不执行 shell，不接受用户提供的任意路径或 bundle ID。此限制是内置插件自身的动作校验，不是操作系统安全边界。
- 图标按结果需要读取，生成 64×64 PNG 并缓存；没有外部图片 URL 或任意本地文件加载。

## 兼容协议扩展

API 版本仍为 1，新增字段可省略：

- Manifest Command `execution: "direct"`：用户选中结果后直接调用命令；省略时保留原有输入表单交互。
- Manifest Command `searchOnly: true`：不进入静态命令索引，但仍可由同插件动态结果引用。启动命令借此避免出现没有目标应用的静态入口。
- `CommandResult.dismiss`：成功后请求可信 Shell 隐藏窗口。Shell 会检查当前交互代次，避免旧交互完成后影响已重新呼出的窗口。
- `SearchItem.icon`：仅接受 PNG data URL；宿主限制整个字符串为 24 KiB、尺寸不超过 128×128，拒绝外链、SVG 和文件地址。无图标时使用原有符号。

第三方隔离视图不能调用新增的可信 Shell 隐藏绑定。原有命令示例保留表单；API 1 老宿主不认识新的 manifest 字段，安装会拒绝，需要更新宿主。

## 验证与限制

- 单元及竞态检查覆盖目录过滤、链接去重、稳定 ID、中英文匹配、英文首字母、刷新、并发查询、取消保留快照、任意输入拒绝和应用移除后的启动拒绝。
- 原生 Bundle 测试覆盖 plist、链接和 loctable 读取；清空 HOME 后仍通过用户账户信息找到 `~/Applications`，适配宿主清理进程环境的行为。
- 浏览器使用实际 Shell 和 Wails 事件路径、模拟 IPC，覆盖搜索未结束时键盘导航及直接动作只执行一次、隐藏而不进入表单。
- 实际宿主 CLI 安装并查询应用插件，返回中文计算器及经宿主校验的 PNG；随后通过真实插件进程启动计算器，收到成功隐藏动作。
- `make test`、`go vet ./...`、前端类型检查与 `make package` 通过。
- macOS 26.6 arm64 的一次独立进程测量：`calculator` 首次查询约 172 ms（包含目录、名称和首个图标），随后 `safari` 约 2 ms、`计算器` 小于 1 ms。单次测量不代表 P95，首次结果尚未达到架构中的本地应用 P95 ≤100 ms 目标。

未实现自定义目录、拼音、历史排序、应用安装事件监听、受控系统 Host API 或 Windows/Linux 应用检索。公共第三方 UI 仍受 ADR 0003 的限制。
