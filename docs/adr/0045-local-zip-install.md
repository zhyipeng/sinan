# ADR 0045：本地 ZIP 插件安装

日期：2026-11-12

状态：已实施；真实文件对话框交互尚未验收。

## 决策与原因

插件管理在已有目录安装入口后增加“选择 ZIP”，支持直接填写 ZIP 的绝对路径，避免用户必须手动解压发行包。UI 保留在 `system.plugin-manager`；宿主仅增加可信组件可用的 ZIP 文件选择适配器，目录安装行为保持兼容。

本地 ZIP 通过 `internal/plugin/distribution` 的通用暂存机制读取，并复用商店的受限解压逻辑。压缩文件和解压内容各限 64 MiB，最多 2048 个条目，拒绝路径穿越、重复路径、符号链接及特殊文件；包根目录必须直接包含 `manifest.json`。保留后端可执行位。

检查与安装各创建独立临时快照，操作结束或失败即清理。安装再次解压当前 ZIP，交由内核按检查时的包内容指纹和已安装指纹核验，源包或已安装包内容变化需要重新检查。继续使用既有原生信任确认、升级回退和视图撤销流程，不自动启动插件。

## 影响与边界

没有新增第三方 UI Bridge、stdio 协议、授权或签名能力。本地 ZIP 无商店目录身份及资产摘要背书，不宣称具备签名认证或操作系统沙箱。不同压缩方式但相同解压内容视作同一包；校验绑定的是安装内容。

无界面回归覆盖本地 ZIP 安装、升级、源内容变化拒绝、原生信任、受限解压和临时目录清理；真实文件选择对话框仅在用户明确要求时验收。
