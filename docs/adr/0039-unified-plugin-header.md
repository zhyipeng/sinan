# ADR 0039：插件页面统一页头风格

日期：2026-11-11。状态：已实施，无弹窗检查通过；真实 UI 未验收。

## 决策

用户要求插件页面与插件管理保持一致，尤其 header。保留动态页面隔离，统一由宿主绘制的原生页头，不在第三方页面中模拟可信导航。

原生页头对齐可信 .view-header：58 DIP 高、16 DIP 横向留白、12 DIP 控件间距、15pt 中等标题、11pt 来源、18pt 箭头图标、7 DIP 按钮圆角、1 DIP 底部分隔线，以及 hover 和键盘焦点提示。返回显示 ←，拆出显示 ↗，快捷键移至 tooltip；无障碍标签保留明确动作名称。标题和来源支持尾部省略。

私有会话绑定/初始化元数据增加 headerTitle、headerSource，来自宿主当前清单，不由页面声明自己的导航。无独立视图标题时显示插件名；视图标题不同时主标题显示视图名、旁边显示插件名。操作系统窗口标题保持原有组合语义。私有初始化消息仍为版本 1，严格旧 helper 无法接受新增字段，因此宿主和 helper 必须同步构建交付；不是公开协议的独立兼容升级。后端 API 1、UI 桥 2 不变。

主题背景、文字、弱文字、分隔线、hover 和焦点色均取现有 ThemeState token，浅色/深色/系统模式变化一并刷新原生页头和页面。

拆出迁移同一容器与同一 WKWebView，不重新加载 React；保留与可信管理页一样的页头，将返回改为 × 关闭窗口，并隐藏拆出按钮。宿主私有返回/拆出/关闭行为与生命周期撤销保持。

## 验证

`make test`、`go vet ./...`、`make build` 和 `git diff --check` 通过；覆盖原生代码编译、标题/来源元数据、私有客体进程和既有返回/拆出无界面控制器检查。真实桌面、WebView 与浏览器交互未运行，颜色、悬浮、键盘焦点和迁移后的实际布局仍待按需人工验收。
