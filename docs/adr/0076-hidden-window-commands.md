# ADR 0076：隐藏窗口执行命令与截图双入口

日期：2026-11-17。状态：已实现，已随截图 0.1.0 与宿主 0.4.0 发布；系统截图及三端真实桌面仍待验收。

## 需求和决策

用户要求截图插件提供两个搜索入口：“截图”直接进入系统选区、隐藏 Sinan 主窗口，结束后自动进入后处理；“截图后处理”直接打开原编辑器。全局截图热键经用户确认，默认 macOS Command+Shift+A，Windows/Linux Ctrl+Shift+A，并沿用设置中的插件快捷键录入、持久化、冲突提示与生命周期撤销。

业务留在独立 `tools.screenshot` 插件。宿主新增通用会话接口，不按截图插件 ID 或命令名硬编码：

- manifest 命令可声明 `startHidden: true`，要求进程插件、HTML 视图、UI Bridge 2 及该视图 `window.execute` 权限，禁止 searchOnly。宿主在加载页面前隐藏所属窗口与主窗口；全局快捷键跳过预先显示 Shell。
- 页面 SDK 新增 `executeHidden(commandId, input)`，对应 `window.execute`。宿主只接受当前活动会话、该视图明确列出的同插件后台命令，不接收插件身份、窗口 ID 或文件路径能力。内核在执行前重新核对原始会话所有权、包指纹、生命周期与命令列表。
- 仅此调用有 125 秒预算，普通 UI 调用保留 500ms。Windows WebView2 页面兼容层仅对该方法采用 127 秒等待，普通调用仍为 2 秒。会话并发、字段校验、请求/响应及资源数量和字节预算保持原值，不放宽 CSP。
- 宿主隐藏所属窗口和 Sinan 主窗口，等待 180ms 供合成器更新，再执行后台命令；普通结果结束后仅恢复仍属于原会话的窗口；同日按用户后续指令，截图取消或未生成图片时通过既有 CommandResult.dismiss=true 撤销临时编辑视图，主窗口保持隐藏，不进入后处理。被替换、禁用、卸载、重载或关闭的会话不恢复旧窗口。其他拆出窗口不受影响。
- 同窗口只允许一个窗口任务，不与自动粘贴并发；同插件有活动或待启动窗口任务时忽略重复全局热键。隐藏页面五秒内没有启动窗口任务时恢复页面，加载失败时恢复当前窗口，避免无可见错误的隐藏状态。托盘和呼出热键仍是恢复入口。

`tools.screenshot` 的 capture 命令声明 startHidden 和 CmdOrCtrl+Shift+A，open 命令保留为“截图后处理”。页面读取启动上下文，仅 capture 自动执行 capture-region；编辑器内的“区域截图”也走 executeHidden。后台在可取消 stdio 请求中等待私有截图任务完成，并在 Go 中维护租约，不依赖隐藏页面轮询。成功后页面自动读取原图并进入既有标注流程，取消、无文件、空图片或无效 PNG 时后台返回 dismiss=true，宿主清理当前视图并保持隐藏；有效 PNG 才恢复后处理。后台隐藏入口遇通信失败也清理临时页面。系统 Esc 取消仍由各平台选区实现处理。

## 兼容与边界

新增 `ui.window-execute.v1` 宿主能力供初始化核对；官方截图插件要求配套本轮宿主，已发布 v0.3.1 和此前 0.2.1 均不足以运行新版截图流程，不能仅凭最低版本号推断支持。manifest Schema 和 Go 校验同步扩展，SDK 快照保持原来源提交并附可重放补丁及文件摘要。默认的嵌入式承载提供该窗口机制，未配置 UI Host 的 CLI 不提供窗口操作。

截图平台捕获本身没有改变：macOS screencapture；Windows 系统 PowerShell/WinForms/GDI；X11 scrot；Wayland 仅受支持合成器的 grim/slurp，GNOME/KDE Portal 尚未接入。180ms 是等待策略，不等于三端合成器隐藏已实机验收。独立进程仍不构成系统权限沙箱。登记仓库没有新版真实发布资产，无需更改目录格式或登记伪造版本。此决策替代 ADR 0075 中手动呼回与无全局截图热键的交互限制，其他图像、保存及隔离边界仍适用。

## 验证

本机 macOS arm64：标准 `node scripts/desktop.mjs test` 通过前端类型检查/生产构建、19 项 JS 无界面检查及全仓 Go 竞态回归；最终窗口任务、权限、预算与撤销用例另经定向竞态检查通过。标准 `node scripts/desktop.mjs build` 在最终实现上通过本机宿主及配套程序构建。官方仓库通过 121 项 JS、11 项 Python 和五个后台竞态检查，截图新增到 8 项 JS、9 项 Go；六目标截图 build/vet、通用打包、六份 ZIP 清单/图标/摘要与本机临时宿主 inspect 通过。真实本机插件进程在模拟 Host API 下通过约 1 MiB / 29 块 PNG 的上传、复制失败重试、标识重放拒绝及 stdio 关闭退出；没有调用真实捕获 API。SDK 增量补丁从 UPSTREAM 所列提交重放后逐文件摘要一致。

Windows arm64/amd64 的 manifest、uiview、kernel、desktop 测试程序交叉编译和静态检查通过；Linux arm64/amd64 的 manifest、uiview、kernel 测试程序交叉编译和静态检查通过，Linux 桌面本轮未原生构建。以上未在 Windows/Linux 执行，macOS amd64 宿主本轮未构建。Windows CI 追加纯数据窗口任务、隐藏命令声明及桥预算用例，三平台 CI 尚未远端执行。只执行无界面测试、静态检查、构建、模拟 Host API 与包检查，不触发真实截图、授权、系统剪贴板、原生 WebView 或浏览器。三端热键冲突、焦点恢复、窗口隐藏时序、中文输入法、多屏/DPI 和 Linux X11/Wayland 合成仍待实机验证；交叉编译不代表目标平台执行，CI 配置不代表远端通过。

## 同日补充：无图片时结束截图

用户明确要求取消或未生成图片时不打开后处理。复用已有 CommandResult.dismiss 字段：仅 window.execute 解释该标志，普通 command.execute 仍不改变窗口；宿主不解析 Text 中的截图业务 JSON。dismiss 时仅移除当前匹配的视图、递增打开序号并撤销会话和原生承载，主窗口定向重置搜索但不显示，拆出窗口关闭且不唤起主窗口。已被替换的视图无权关闭新会话。隐藏启动的命令通信失败同样清理临时页面；普通已打开页面的非业务通信错误保持原恢复策略。

未新增协议字段、SDK 方法或权限，沿用本轮未发布 ui.window-execute.v1 能力；官方 SDK 快照无新增修改，登记仓库无变化。组件选型按用户要求仅比较，不安装或替换现有手写编辑器。候选调查见[图片编辑组件比较](../research/screenshot-editor-candidates.md)。

本轮取消分支验证：macOS arm64 标准无界面回归及本机构建通过，最终隐藏入口通信失败与取消分支另经窗口任务定向竞态检查及标准构建通过。官方仓库 121 项 JS、11 项 Python、五个后台竞态检查通过，截图 Go 用例增至 10 项，新增取消/无文件/空图/非法 PNG 不显示后处理及有效 PNG 正常呈现；宿主覆盖 dismiss 标志解析、仅原会话清理和旧会话不能移除新页面。截图六目标重建与通用打包、模拟 Host API 的真实 stdio 合成图片检查通过。Windows arm64/amd64 桌面测试程序交叉编译/静态检查与截图六目标静态检查通过；Linux 桌面本轮未原生构建，未运行三端真实截图、授权、窗口或 WebView 验收。
