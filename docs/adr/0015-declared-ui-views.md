# ADR 0015：受限 UI 资源声明与默认拒绝

- 状态：声明校验与内部会话接入已实施；日常桌面加载入口待实施
- 日期：2026-11-05
- 后续：[ADR 0017](0017-desktop-plugin-windows.md) 已提供默认关闭的桌面开发入口和普通客体；本文未接入桌面的描述为当时阶段记录。

## 原因

已有会话和独立客体监督，但内核准备接口允许内部调用者选择任意 UI 入口路径，也没有声明桥版本或 UI 权限。公开加载前必须明确资源选择和权限边界，避免可信组件、原生后端用途声明与 HTML 页面之间出现隐式授权。

## 决策

- 在 `packages/plugin-protocol/ui.go` 定义 UIView，Manifest 在 `contributes.uiViews` 使用该类型，Schema 同步描述结构。每插件最多 4 个，ID 唯一且最多 64 字符。
- 入口固定相对于已安装包 `ui/`，仅支持规范 ASCII 相对 `.html` 路径，最长 256 字符、最多 8 个目录层级。拒绝 URL、路径穿越、转义、查询和片段。打开时继续执行资源快照限制和前后包指纹检查，缺失或不支持的资源不发布会话。安装期校验声明语法，不提前加载页面。
- `bridgeVersion` 必填且当前仅字符串 `"1"`，独立于后端 API 和私有进程管道版本；不支持的版本拒绝，不回退。页面 ready 消息仍按现有版本 1 语义检查。
- UI 权限单独声明，省略或空数组表示无 Host API 权限，任何非空请求均拒绝；当前只允许插件 UI 资源读取、一次 ready 和 close。顶层 applications.read / applications.launch 仍是可信原生后端的用途声明，不继承到 UI。没有新增可授权权限列表、授权持久化或系统权限沙箱。
- `OpenUIView(ctx, pluginId, viewId)` 只选择已安装实例声明的 ID，不接收入口覆盖。会话绑定额外保存视图 ID 与桥版本，构造时验证；仍受启用、包指纹、实例替换和生命周期撤销控制。
- 资源归属仍按插件划分，同插件多个视图共享 `ui/` 快照授权范围，不能声称具备视图间资源隔离；该目录只放适合交付页面的资源。
- `commands[].view` 继续表示构建时注册的可信组件。若与本插件声明的 HTML 视图 ID 同名，校验拒绝；尚不增加命令到 HTML 的映射、Wails 绑定或公开 RPC。
- 原生固定夹具声明三个独立入口，开发验证按 ID 打开，不提供绕过声明的原始路径分支。

## 兼容性

Manifest API 1 增加可选字段，现有插件无需修改，后端 JSON-RPC 和系统可信组件语义保持。旧宿主通过未知字段校验拒绝含 UI 声明的包，不会静默降级。内部 OpenUIView 参数语义改变，所有开发调用与测试同步迁移；这不是已发布的插件 RPC 破坏性变化。

静态 Schema 约束结构、版本、入口形状及空权限；Go 校验另外检查 ID 唯一、可信组件冲突及打开时的实际文件和实例状态。

## 验证

- 声明测试覆盖重复 ID、数量上限、空/错误版本、非空 UI 权限、后端权限不继承、未知字段、可信组件同名和非法入口。
- 会话测试覆盖视图与桥版本绑定；内核测试覆盖未声明 ID、直接入口绕过、无声明包、缺失资源、升级移除声明后旧句柄失效且不能重新打开。原有生命周期、并发和监督测试继续通过。
- 原生开发验证使用声明 ID，正常关闭、洪泛撤销和真实内核禁用三种独立进程模式均通过。

## 后续

需要补齐渲染异常、页面挂起和资源耗尽处理，再接入日常桌面宿主的受限窗口入口与真实交互验证。声明能力不代表任意第三方页面已可公开加载，也不代表渲染资源或操作系统权限已受安全沙箱限制。
