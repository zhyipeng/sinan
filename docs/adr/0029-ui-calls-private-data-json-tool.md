# ADR 0029：按会话授权的 UI 调用、私有数据与 JSON 工具

日期：2026-11-09。状态：已实施。

## 背景

独立 HTML 客体此前只支持 ready / close，无法验证业务交互和持久化。用户选择 JSON 格式化作为本轮实用插件，不增加 demo 插件。

## 协议与授权

保留 UI 桥 1 的原行为；桥 2 显式声明 `commands` 白名单和可选 `permissions: ["storage"]`，使用 ready version 2。未知版本、权限、重复或不存在的命令、视图命令及声明式后端命令引用均拒绝。旧宿主不能接收这些新包；后端 RPC API 仍为 1，不增加任意方法调用。

可信 macOS 客体仅为桥 2 注册带 Promise 回执的 `sinanCall`，检查主 frame、固定入口 URL、请求类型和大小；CSP、导航与资源限制继续生效，不注入 Wails Bridge。原生线程将请求放到后台处理、在主线程回执，退出前撤销并等待已接收请求结束，避免阻塞 AppKit 事件循环或访问已释放的 Go handle。

页面请求不能指定插件 ID、路径或宿主方法。内核从 Session 对象追溯原实例、视图声明和包指纹。只支持：

- command.execute：调用同一插件白名单中的后端命令，参数为 commandId 和 input；不执行搜索动作、不隐藏面板、不写搜索历史。
- storage.get：读取该插件唯一私有 JSON 文档。
- storage.put：以 revision 比较后原子替换该文档。

拒绝未知、重复、大小写别名、多余字段和非法类型。每会话单次在途、120 次/分钟；请求上限 64 KiB、结果上限 192 KiB，调用预算 500 ms，生命周期或进程锁忙时立即返回可重试错误，避免在 UI 管道中排队等待长操作。SDK 串行调度并限制本地队列为 8。撤销取消在途请求、丢弃迟到结果；沿用现有强制超时机制，后端命令超时或取消可能终止该插件后端进程，其他页面需要重新打开。没有实现按命令独立的合作取消。

目录指纹在调用前检查；生命周期变更不能将旧 Session 重新指向新实例。数据写入持有变更锁，撤销后新请求拒绝；已提交的原子写入不会因页面关闭回滚，页面必须允许“保存已发生但回执丢失”的情况，并通过重新读取 revision 恢复。

## 数据

`.sinan-state/data/<plugin-id>.json` 保存一个最大 32 KiB 的 JSON 值及 revision，独立于插件包、配置与使用历史。只允许普通文件，拒绝符号链接；写临时文件、同步并原子 rename，写入失败保留旧值，文件损坏时拒绝覆盖。独立 JSON 通道不进行 HTML 转义，避免 `<`、`>`、`&` 使已接受的数据膨胀后无法读回；展示时使用 textarea.value / textContent，不拼入 HTML。升级、重载、普通卸载保留数据。本轮不提供任意路径、跨插件访问、删除数据、通用 KV、SQLite 或凭据库。32 KiB 是单插件文档限额，不代表全局磁盘配额或 OS 安全沙箱。

storage 是宿主明确支持的插件私有数据能力，不是通用系统权限管理器；原生进程仍按安装信任运行，有当前用户的系统权限。文件、剪贴板和网络 Host API 继续不开放。

## 实用插件

`tools.json`：独立 HTML 编辑器 → 会话 RPC → Go 插件后端 → 返回格式化/压缩结果；私有文档保存上次草稿。格式化使用原始 JSON 字节，保留数字精度、字段顺序及重复字段，不以 JavaScript Number 重建数据。输入 48 KiB、输出 128 KiB、嵌套最多 128 层；语法错误返回行列，保留输入。

输入停止 700 ms 后保存草稿；显示“草稿已保存”才表示写入已确认。立即关闭可能丢失尚未提交的编辑。冲突或失败保留当前输入，暂停自动写入并提供显式载入旧草稿；数据读取失败仍允许格式化。Command/Ctrl + Enter 格式化，加 Shift 压缩。窗口拆出沿用已有机制，不重建页面。

## 交付与验证

`make json-plugin` 构建到 bin/plugins/json-tool，包含独立 SDK JS；`make dev-ui` 准备开发插件并显式启用 HTML 客体，`-plugin-ui` 仍默认关闭。不自动修改日常插件目录。可信设置和管理界面不迁移到此桥。

回归覆盖清单权限、严格请求结构、跨插件身份伪造、命令白名单、未握手/未授权/撤销会话、超时、数据冲突/损坏/符号链接、重载与升级保留数据。真实 WebView 使用实际 JSON UI、后端和 SDK，验证格式化、压缩、大整数、错误输入保留、越权拒绝、重建宿主后草稿恢复、拆出后继续调用与保存，以及接近文档限额的 HTML 字符往返；浏览器夹具仅检查界面交互与布局。公共分发、通用授权、其他平台承载仍待完成。
