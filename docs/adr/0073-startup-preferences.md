# ADR 0073：启动偏好与当前用户登录自启

状态：启动设置已实现；自启原生实现现由 [ADR 0082](0082-wails-autostart.md) 替代。三端登录和真实窗口行为待实机验收。

## 决策与原因

设置插件在「通用」的外观设置之后增加静默启动、开机自启两个独立开关，即时保存。界面属于 `system.settings`；宿主提供私有可信绑定，内核保存 `$startup.silent` 和修订号，系统注册集中于 `internal/startup`，不开放给第三方插件。

静默启动默认关闭。开启后，下次普通启动直接以 Wails `Hidden` 创建主输入框，避免先显示再隐藏；托盘和呼出快捷键保持可用。切换设置不隐藏当前窗口。损坏配置保留原文件、回退为显示窗口并拒绝覆盖；过期修订号及存储失败均不更新偏好。探测及临时验收始终显示窗口。

开机自启指当前用户登录后启动，默认没有注册项。macOS 写入 `~/Library/LaunchAgents/dev.sinan.desktop.plist`，使用固定 Label、转义后的绝对可执行路径和 RunAtLoad，不立即加载或启动额外实例。Windows 写入 HKCU `Software\Microsoft\Windows\CurrentVersion\Run` 的 Sinan 字符串值，路径整体加引号。Linux 写入 `$XDG_CONFIG_HOME/autostart/dev.sinan.desktop.desktop`，无有效绝对 XDG 路径时使用 `~/.config`，按照 desktop entry/Exec 两层规则转义路径。Linux 依赖桌面会话支持 XDG Autostart，不能推断所有 X11/Wayland 桌面均已验收。

开关每次读取宿主自有注册内容与当前程序路径是否匹配，不把另存的布尔值当作系统状态；写入失败明确报错。文件使用临时文件及同目录替换，关闭仅删除自有配置文件或注册表值，不操作其他应用。开发自定义插件目录、探测和验收实例禁用系统注册，静默偏好仍独立可用。自启不额外强制静默，是否显示由静默开关控制。

## 影响与边界

用户移动便携程序或 macOS 应用后需在新位置重新开启自启，以替换旧路径。关闭、退出应用不会移除自启项；不新增卸载器或清理系统安装记录的能力。macOS 使用下次登录加载的 LaunchAgent，不接入 SMAppService 或启动即时授权流程。注册文件匹配不等于 OS 策略允许实际执行，外部禁用、桌面依赖及系统策略仍须实机核对。

不更改公开插件协议、SDK、manifest、商店格式及权限模型；sinan-official-plugins、sinan-plugin-registry 无需联动。非支持系统显式报告能力不可用。没有新增依赖。

## 验证

无界面测试覆盖偏好默认值/重启/关闭、过期写入、文件损坏及保存失败、自启文件创建/删除/失败、过期路径和原生路径转义；宿主假注册器验证两个开关互不影响及注册失败。所有系统自启测试仅使用临时目录或假注册器，不修改真实自启项。具体本轮构建结果见跨平台文档，不将交叉编译描述为目标运行或登录验收。


## 后续替代

按用户指令，已删除 `internal/startup` 的自行注册实现，改用当前 Wails 3.0.0 的 `app.Autostart`。上文平台写入、下次登录加载和不接入 SMAppService 的描述保留为历史方案，不再作为当前行为。当前平台策略、既有注册复用和验证边界见 ADR 0082；静默启动的配置与行为不变。
