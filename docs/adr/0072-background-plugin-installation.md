# ADR 0072：插件商店后台下载安装任务

日期：2026-11-17

状态：已实施，未发行；桌面交互未验收。

## 原因

商店原有前端先等待下载与预览，再调用应用接口。页面卸载时取消预览，下载完成后也会因组件不再存活而放弃应用；界面生命周期因此决定了安装能否完成。点击安装已经授权这次候选的安装及原生信任，无需由页面持续存活维持授权。

## 决策

- 任务管理器属于内置插件中心的 catalog 服务，由宿主持有单例。UI、状态列表、取消与重试入口仍属于插件中心，不把商店业务迁入内核。
- 新增仅供可信组件使用的 StoreInstall、StoreInstallTasks、StoreCancelInstall 绑定。提交立即返回任务，后台串联既有 Prepare / Apply；使用独立的十分钟 context，不继承 Wails 请求或页面生命周期。
- 状态为 downloading（含目录校验、下载、解压与预览）、installing（应用前复核与提交）、succeeded、failed、cancelled。最多四个活动任务，同一插件复用活动任务，保留最近最多 32 条任务记录。实际包应用沿用内核事务与锁。
- 下载阶段允许显式取消；进入 installing 后拒绝用户取消，避免将不可取消的包提交错误呈现为已撤销。退出时停止接收任务、取消网络工作并等待所有任务及暂存清理完成，再关闭内核。窗口关闭使用主线程异步投递，避免退出主线程等待后台任务时形成死锁。
- 页面每秒读取宿主快照，重新进入可恢复状态；成功后刷新本地插件及 Shell。安装本身不锁定商店导航。失败和取消可以重试，重试先读取最新目录修订。
- 保留目录修订、资产撤回检查、SHA-256 / 大小 / 解压预算、包身份、指纹、本地修改保护及原生信任语义。任务列表不暴露预览票据和本地路径。

## 影响与边界

本轮只改变宿主内任务生命周期和可信组件绑定，不增加公开插件协议、SDK、manifest 或登记格式字段；sinan-official-plugins 与 sinan-plugin-registry 不需要联动改动。原有同步预览和应用绑定保留。

使用共享 Go context、互斥锁和 goroutine，macOS、Windows、Linux 共用实现，不新增平台依赖、WebView API 或权限。隐藏窗口、页面卸载和切换不取消任务；退出应用会取消尚未完成的下载。任务记录仅保存在内存，不提供重启恢复、断点续传、自动更新或系统通知。

无界面回归覆盖立即返回、无页面参与的实际安装、重复提交、并发上限、目录校验失败、取消与重试、退出取消下载、安装提交阶段拒绝取消与等待收尾。Windows CI 追加任务回归；配置不代表远端已运行。具体本轮验证与目标运行限制见跨平台文档。

## 同日补充：独立 Tab 与下载进度

按用户后续指令，在既有「已安装」「发现」之后追加「下载安装」Tab，将任务列表从公共页面底部移入独立面板，Tab 展示活动任务数。切换 Tab 不影响宿主任务，空列表显示空状态。

下载器提供可选进度回调，记录当前候选实际写入缓存的字节，以已核验目录中的资产大小作为总量，不依赖响应的 Content-Length。每次镜像尝试重新计数，不把失败候选的流量累计到新候选。任务快照追加 downloadedBytes / totalBytes，仅在可信宿主绑定中使用，不改变公开插件协议或 SDK；旧 Stager 与同步 Prepare 保持可用。

使用原生 HTML progress，准备目录时显示不定进度，下载时显示大小和百分比，收满字节后显示校验状态，进入 Apply 后显示安装状态。进度只代表归档下载，不模拟解压或安装百分比；失败时保留最后已下载大小。回调更新与读取使用任务锁，沿用每秒快照轮询。

新增无界面用例覆盖分块字节回报、缺失 Content-Length、镜像重试归零及任务中间/最终进度快照。无新增系统接口或权限，三端仍共用 Go 与标准 WebView HTML 元素；真实 WebView 视觉与切换验收待补充。
