# ADR 0033：窗口内快捷键进入设置

日期：2026-11-11。状态：已实施。

用户要求 Cmd / Ctrl + 逗号进入设置。可信 Shell 在窗口内处理快捷键：macOS 为 Command + ,，其他平台为 Ctrl + ,；不注册全局热键。忽略长按重复、组词和额外修饰键，快捷键录入控件已消费的事件不触发导航。

入口经宿主验证已安装的 system.settings/open 声明，再定向通知主窗口进入可信设置组件。若设置已拆出则直接聚焦该窗口，保留编辑状态；独立插件和管理窗口不因导航被替换。

macOS 隔离 HTML 客体由原生事件层识别同一按键，通过私有 window-action/settings 通知父宿主；页面脚本没有新增桥能力。打开主设置前释放附着客体的主面板槽位并撤销其会话，已拆出的客体保持独立。父子私有协议新增动作，需同步构建 sinan-ui-host，页面桥及后端协议版本保持不变。

无界面真实子进程回归覆盖附着与独立两类设置请求、主面板释放和独立会话存活；日常 make test 不启动桌面 UI。真实按键、输入法和焦点仍需显式交互验收。
