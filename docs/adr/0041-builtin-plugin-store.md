# ADR 0041：基于 GitHub 目录的内置插件商店

状态：首版已实现；独立插件身份已由 [ADR 0048](0048-unified-plugin-center.md) 合并为插件中心，以下保留原决策历史。公共分发完整安全治理仍待完成。

## 背景

用户要求新增内置插件商店，并确认首版包含浏览、搜索、详情、安装与手动更新，未发布插件显示待发布。主窗口、官方插件与目录已拆分，现有目录只有 JSON 工具资料。

## 决策

- 新增 `system.plugin-store`，业务 UI 与目录契约放入插件目录。宿主仅绑定可信组件和桥接入口，通用下载与 ZIP 暂存机制位于 internal/plugin/distribution；安装、信任、包指纹、升级与回退继续复用内核。
- 固定读取公开 sinan-plugin-registry main 的审核资料，按树中 blob SHA 获取一致快照。只消费 plugins 内正式 releases，不消费 submissions，不接受任意下载 URL。
- 采用固定 Asset ID、大小、SHA-256、受限解压、一次性预览，以及安装前重新核验目录。更新为用户显式选择，保留配置、数据、禁用状态，拒绝覆盖开发链接或已修改包。
- 商店作为可信内置组件，在同一主窗口复用 Shell 页头与导航；第三方 UI 仍使用原有隔离机制，不增加第三方 Wails Bridge 权限。商店可禁用、卸载。
- 目录无正式版本时只显示待发布，不伪造发行版本或资产。

## 影响与限制

新增目录发布记录 v1，正式版本必须提供 minHostVersion。目录仓库同步升级本地校验器；旧模板提交材料在审核纳入前补齐字段。目录分支的审核与维护者权限属于分发信任根。

首版尚未实现独立目录签名、密钥轮换、完整撤销体系和自动更新。架构基线的公共分发前签名要求没有完成，不能将 HTTPS、Git 提交摘要或包哈希描述为作者签名；当前实现不代表公共第三方生态已就绪。下架不自动处置本地已安装插件。平台兼容筛选不代表所有目标平台均已实机验证。

具体协议、配额、维护与测试范围见 [插件商店](../plugin-store.md)。
