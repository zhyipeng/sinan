# ADR 0013：UI 会话的实例绑定与撤销

- 状态：内部机制与原生开发验证已实施；公开插件 UI 仍未开放
- 日期：2026-11-05
- 后续：[ADR 0014](0014-ui-guest-supervision.md) 已将原生开发客体迁为独立进程；本文同进程 cgo 与同步原生信号描述为本阶段记录，跨进程撤销以新 ADR 为准。
- 声明演进：[ADR 0015](0015-declared-ui-views.md) 已增加受限 Manifest 声明，并将准备接口从入口路径改为视图 ID；本文无声明接口的描述为当时阶段记录。

## 原因

ADR 0012 的固定资源快照和原生导航拦截不能单独回答：插件禁用或包被替换后，已打开页面还能否读取资源和发送消息。整包复制到客体也不适合实现逐次授权。因此本轮建立内核持有的会话，并让开发原生宿主使用相同的资源与消息检查路径。

## 决策

- 内核内部准备接口 `OpenUIView` 固定选择已安装包的 `ui/` 子目录，拒绝不可用、禁用、已移除或待重载实例。加载资源前后比较当前包内容指纹与注册基线，取消或校验失败不发布会话。不激活原生后端。
- 会话记录插件 ID 与包指纹，授权依据是宿主持有的会话对象，而不是可由页面填写的 ID 或指纹。实例替换后必须新建句柄；旧对象一旦撤销不可恢复，即使升级回退或重新安装了相同字节。
- 每插件最多 4 个、每宿主最多 16 个活动会话，关闭的槽位可复用。创建与包/策略变更使用同一管理变更锁；运行进程故障通过实例会话代数变化阻止在途创建跨越撤销点发布。
- 会话逐次检查资源 URL 并返回副本；协议仅支持一次严格 ready 握手和 close。拒绝超大、额外/重复字段、重复握手、伪造归属和未知动作。每条 4 KiB、每会话 32 条消息，耗尽后撤销。没有文件、执行、设置或通用数据 API。
- 禁用、停止、成功重载、进入升级替换、卸载、宿主关闭、成功配置保存及运行实例故障都会撤销会话。刷新、打开、检查包和重载等步骤观察到包文件变化时也撤销；失败回退不会复活旧对象。无变化的升级不撤销。策略/配置保存失败不改变旧会话。
- 显式停止纳入管理变更锁，避免与打开/替换并发时停止了旧实例却留下新会话。失败重载仍可保留原运行实例，但若检测到包已变，旧 UI 必须撤销。
- 撤销在锁内将会话置为失效、释放资源快照并关闭 Done；随后同步执行取消信号。并发撤销等待信号完成，确保生命周期成功返回前原生请求入口已关闭。取消监听器只能发信号，不得重入会话或内核；移除监听不等待在途调用，原生适配器用独立生命周期锁保护 C 状态的释放。

## 原生验证宿主接入

开发程序把内嵌固定测试资源安装到独立临时插件根目录，不使用日常实例。通过 `OpenUIView` 获取会话，只把入口和 CSP 元数据传给 WKWebView。旧的整包 JSON 导出路径已移除。

原生 Scheme 处理器经私有 cgo 句柄逐次访问该会话；ready/close/未知消息也进入会话校验。消息仍在原生层检查主框架和原入口文档，开发报告消息不参与通用协议。句柄不传给页面，页面提供的插件 ID 不能选择其他会话。

撤销监听同步设置原子信号；原生资源、导航和消息入口检查该信号，主循环结束后移除处理器和 delegate。返回 Go 释放句柄前将原生句柄置零，晚到回调无法访问已经释放的会话；C 状态释放与取消监听使用独立锁串行保护。

新增仅固定探测页使用的 `-revoke` 模式：报告完成后由宿主绑定的诊断动作调用真实内核禁用同一临时插件，不能填写其他插件或执行其他操作。该诊断动作不是 `Session.Message` 的公共能力，普通会话只能 ready/close。

## 验证

- Go 竞态测试覆盖资源读取与并发撤销、严格消息结构、重放、超限和通知；撤销后资源与消息均拒绝。
- 内核测试覆盖禁用/重新启用、停止、成功重载、升级、卸载、关闭、文件变化发现、会话限额、取消及并发读取。初始化失败回退到相同指纹后旧句柄仍失效；策略写入失败保留旧会话，检测到变更的失败重载则撤销旧 UI。
- 本机 macOS 26.6 / arm64 的 `make ui-probe` 运行正常、洪泛、真实禁用三种进程，均退出 0。正常模式接受 close，洪泛模式预算撤销，禁用模式生命周期撤销；三种模式的 `sessionRevoked`、`staleResourceDenied`、`staleMessageDenied` 均为 true，HTTP 正对照通过且逃逸端点未收到请求。

## 限制及后续

会话只影响撤销后继续发生的宿主请求，不能收回已经给页面的字节或回滚既有外部动作。外部磁盘变动在刷新/打开等校验点观察，尚无文件系统监听，也没有对恶意同用户并发修改文件提供原子快照保证。

这轮没有新增 Wails 绑定、进程 RPC 或公开 manifest UI 声明。原生验证宿主和管理器暂处于同一开发进程，只证明会话资源/桥接与原生撤销信号连通；它未实现正常桌面宿主监督独立客体进程。下一步需定义私有传输、进程握手、退出及超时回收、权限默认拒绝与异常预算，再开放公开承载。

可信原生插件仍拥有当前用户权限，不能据此宣称文件权限沙箱；cgo 句柄是进程内实现细节，不是面向不可信进程的认证协议。原有 stdio API 1、系统可信组件和搜索 Shell 的承载方式保持不变。
