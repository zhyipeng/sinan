# ADR 0001：首轮实现边界与插件协议

日期：2026-11-04。状态：采用；用户确认按 Phase 1 开始。

## 背景

项目从空目录启动，需要先证明插件可独立安装、执行、停止和卸载。完整的搜索、隔离 UI、设置存储和插件市场尚未进入实现阶段。

## 决策

- 首先在当前 macOS arm64 环境验证。使用 Wails `v3.0.0`、Go `1.26.0`，前端为 React + TypeScript + Vite；依赖以 `go.sum` 和 `package-lock.json` 锁定。
- macOS 构建沿用 Wails 官方构建模板的 12.0 deployment target，提供本地未签名 `.app`。仅本机新系统验证通过，不代表已完成 macOS 12 或其他系统版本兼容验证。
- Go 模块暂用本地名称 `sinan`，不虚构远程仓库。统一 Go 模块包含宿主、协议、SDK 和示例源码；插件分开构建为独立二进制，宿主不导入示例插件。
- 以最小命令 Shell 操作插件。Shell 内的本地安装、停止、卸载和错误展示属于启动期恢复入口，完整插件管理业务将在后续系统插件中实现。
- 本地目录导入作为第一种安装方式，复制到插件 ID 对应目录。暂不支持 ZIP 包、更新覆盖或签名。已存在插件拒绝覆盖，先卸载再安装。
- 提供 `example.hello` 声明式插件和 `example.echo` Go 独立进程插件。示例均不请求系统 Host API 权限；原生插件必须在安装时明确确认信任。
- 信任记录由宿主保存于插件根目录下 `.trusted/`，不读取 manifest 中自称的可信属性。这不是安全沙箱，也不防御同一用户修改插件文件或信任记录。
- v1 使用 UTF-8、每行一个完整 JSON 对象的 JSON-RPC 2.0，不支持美化跨行 JSON。stdout 专供协议，stderr 丢弃，不把任意插件输出直接写入宿主日志。
- 请求采用非零递增数字 ID，先 `initialize` 校验 API 版本与插件 ID，再 `command.execute`。每次执行总超时 5 秒，单条消息上限约 1 MiB，命令输入上限 64 KiB。
- 当前请求取消/超时以终止进程实现；停止为强制终止并回收进程；再次执行时重新激活。暂不支持协作取消通知、优雅 shutdown、心跳、流式结果、背压调度或自动重启。
- 当前生命周期为 installed → activating → running，声明式执行后为 activated；停止为 deactivated，运行异常为 failed。尚不支持 suspended。
- 运行时管理操作暂时串行化以保证状态一致；后台持续任务、多 Provider 并行搜索在后续阶段设计。
- 不继承宿主环境变量，不转发插件错误正文，不向插件开放宿主 Wails Bridge。进程仍以当前用户身份运行，环境裁剪不等于权限隔离。

## 影响与验收

首轮可在不重建宿主的情况下导入插件并运行命令。独立进程崩溃、无响应或非法协议输出应只使对应插件失败；其他插件仍可执行。

真实进程集成测试覆盖安装信任、握手、命令、停止后重启、重新发现、卸载、超时、崩溃、非法输出、符号链接拒绝与并发访问。

动态 UI 隔离与多 Provider 搜索仍是下一步技术验证。当前 UI 仅渲染宿主可信代码和文本结果，不加载第三方 UI。阶段性实现不构成公共第三方插件分发能力。
