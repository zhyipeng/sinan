# ADR 0023：可信组件原窗口拆出

- 日期：2026-11-09
- 状态：采用
- 补充：ADR 0022 的主面板交互；覆盖其“可信组件不提供拆出”的阶段限制

## 背景

用户明确以设置页为例，要求当前主窗口中的插件界面按热键拆出。上一轮只支持隔离 HTML 客体，尚未覆盖设置和插件管理这两个可信 React 组件。

## 决策

保留当前可信 Wails 窗口及 WebView / React 树，转换其窗口呈现；创建新的隐藏搜索面板，替换 launcher 当前窗口引用。拆出不刷新页面、不传输或落盘表单草稿，未保存输入、滚动位置及组件状态沿用原实例。当前固定组件注册表仅包含设置与插件管理，后端也校验已安装且启用的命令及同一白名单，不将 manifest 视图字段变成任意代码加载入口。

macOS 独立工具窗口保留原 NSPanel 类型及非激活样式，启用标题栏、调整大小，关闭置顶与跨 Space 特性。不在已有 NSPanel 上切换 nonactivating 位，避免 AppKit 状态与 WindowServer 激活标签不一致；它不是重新创建的 NSWindow。

主窗口引用和独立窗口注册表受锁保护。调用者必须来自 Wails WindowKey 中登记的真实窗口，旧窗口的 ResizeLauncher / HideLauncher 不影响新主窗口。搜索结果回到发起搜索的当前主窗口；设置与快捷键状态同步到各可信窗口；录入取消仅作用于所属窗口，不能由另一窗口的失焦或清理取消。

Command + Shift + D 使用页面键盘处理，不拦截输入法组合、重复按键或已经被录入控件消费的事件。拆出后移除主面板 Escape 绑定，使 Escape 可由组件正常处理。顶部返回改为关闭独立工具；失焦不隐藏，主面板显隐不联动。插件禁用、卸载、重载、升级和应用退出仍会回收对应窗口。

## 验证与限制

真实 macOS 临时实例已验证设置和管理页的快捷键拆出、标题栏、管理目录草稿保留、设置快捷键草稿保留、拆出后的快捷键录入及保存、关闭后新搜索面板仍可使用。自动回归覆盖可信声明白名单、窗口角色与调用者身份、失效窗口拒绝、录入取消归属。

真实系统全局热键跨窗口切换、三屏及全屏仍需按手动验收补测。第三方 HTML 无法调用本接口，不获得可信 Wails Bridge；原有独立客体隔离方案保持不变。跨平台表现未在本轮实测。
