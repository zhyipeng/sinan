# ADR 0022：逻辑主面板与同页拆出

- 日期：2026-11-06
- 状态：采用
- 取代：ADR 0020、0021 中默认独立打开的呈现策略；协议与隔离约束继续适用

## 背景

用户要求 uTools 式交互：默认在主窗口使用插件，按 Command + Shift + D 拆出后与主窗口独立。Command + Space 保留主窗口显隐职责。已有 HTML 运行于固定独立客体，跨进程 NSView 不能直接嵌入 Wails 窗口；将页面放回可信 DOM 会破坏既定边界。

## 决策

采用两个原生窗口互斥呈现的逻辑主面板。搜索由 Wails Shell 承载；声明式 HTML 由独立客体的无边框、非激活 NSPanel 替代搜索位置。面板在鼠标屏幕横向居中，顶部位于可用区域 20%，失焦隐藏。主面板仅保留一个附着客体，切换视图释放旧附着会话，已拆出的客体保留。

原生头部提供返回和独立按钮，不由插件 HTML 绘制。返回关闭当前会话并恢复搜索；拆出采用同进程迁移现有 WKWebView 至普通 NSWindow，不重新请求入口或重建文档。拆出后解除父进程的主面板关联，重复打开仍聚焦原窗口。失焦隐藏只适用于附着面板。

私有控制管道扩展 toggle / detach，与 focus 共用单调编号、单个在途请求和有界确认；可信原生层使用 window-action 告知父进程 detach / back。父进程只对 Panel 模式及当前附着实例接受操作，页面 ready / close 协议未扩权。撤销、禁用、卸载和宿主退出继续回收独立窗口。

## 影响与限制

- 保留独立进程及窄桥边界，不构成操作系统安全沙箱。
- 逻辑主面板不是跨进程原生视图嵌入，切换时存在原生窗口交接。
- 设置、插件管理仍为可信组件，本轮不提供它们的拆出。
- 默认尺寸为 680 × 530（头部 50），按屏幕剩余高度裁剪；动态内容高度及位置持久化另行设计。
- 原生回归验证同一文档输入在显隐及迁移后保留；真实快捷键、三屏、全屏和中文组词需人工验收。
