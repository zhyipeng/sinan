# ADR 0056：官方剪贴板插件与系统输入机制

日期：2026-11-14。状态：已实现，无界面回归通过；系统热键、剪贴板及跨应用输入的真实 UI 验收未执行。

## 决策与原因

用户要求创建支持文本和图片、本机持久化的剪贴板插件，用 Command/Ctrl + Shift + V 直接打开选择界面，选中后隐藏并自动粘贴到原应用。遵循 All-in-Plugin，将 `tools.clipboard` 0.1.0 放入独立官方插件仓库，使用经原生信任确认的 Go 进程及隔离 HTML 页面；不加入内置插件保护集合，不自动安装或发布。

宿主只新增通用机制：

- 命令可选 `shortcut` 关联已声明 `uiView`，`CmdOrCtrl` 按平台解析。桌面每秒协调有效插件声明，处理冲突、禁用、移除与重新注册。冲突在可信插件中心诊断中显示，插件仍可按名称打开。现有主呼出快捷键先注册，插件注册不抢占已有组合。
- 原生插件可声明 `onStartup`，桌面启动、安装及恢复启用后激活；后台进程退出后恢复，失败间隔五秒重试。显式“停止”也会被该声明重新激活；需要持续停止时禁用插件。宿主关闭时取消协调，释放插件热键，再关闭运行时。
- API 1 initialize 增加可选绝对 `dataDir`，位于 `.sinan-state/native-data/<pluginId>`。目录创建失败阻止该进程启动；升级、重载、禁用、卸载保留数据。与可丢弃 `cacheDir`、现有 UI JSON 文档服务分开，当前插件中心私有文档占用/清理不涵盖此原生目录。旧插件忽略增量字段，依赖此字段的新插件需要新版宿主。
- UI 桥 2 增加无参数 `input.paste` 与显式视图用途 `input.paste`；入口继续检查包指纹、实例、会话、声明、预算和撤销。页面不能指定 PID、窗口、路径或按键。普通嵌入视图绑定宿主呼出前捕获的目标；拆出沿用此目标。旧独立 helper 路径不提供此动作。

页面先通过本插件命令将所选条目写入系统剪贴板，再请求宿主粘贴。宿主检查目标及平台条件，隐藏当前窗口、恢复原应用，并在发键前复核焦点、会话及当前视图。成功后先回复页面，再回收视图；失败保留已复制内容并恢复页面，通过原有 Promise 返回错误。原应用关闭、权限缺失、焦点切换和系统输入策略仍可能导致失败，不承诺向所有应用输入成功。

## 插件职责与存储

插件进程每 500 ms 检查剪贴板，只记录文本和静态 PNG 图片。内容散列去重，最近复制排前；最多 200 条、有效内容总计 64 MiB、单文本 256 KiB、单 PNG 8 MiB / 1600 万像素。图片原生格式先转换为 PNG。历史以用户私有目录及文件权限、临时文件和原子替换保存；索引损坏不自动覆盖，读取条目核对摘要。文本预览和缩略图按桥接预算限制，选择时写回完整内容。PNG 缩略图以有界 RGBA 数据绘制 canvas，不放宽 CSP 或开放数据 URL。支持全文搜索、键盘上下选择/Enter 粘贴、复制、删除及清空。

这些文件未加密；本机历史不会发送到目录服务或网络，内容不进入日志或宿主搜索使用记录。macOS 跳过 Concealed / Transient / AutoGenerated 标记，不承诺识别所有敏感内容。原生用途新增 `clipboard.read` / `clipboard.write`，仍属于信任用途说明，不构成 OS 沙箱或完整权限授权器。

## 平台和验证边界

macOS 使用 NSPasteboard 与宿主 CGEvent，自动输入需要用户在系统设置为司南开启辅助功能权限；缺少权限时按下述后续调整弹窗引导。Windows 使用 Win32 剪贴板与前台窗口校验，受系统前台切换和完整性级别限制。Linux 剪贴板需要 `xclip`（X11）或 `wl-clipboard`（Wayland）；自动粘贴仅支持 X11 + `xdotool`，Wayland 无通用焦点恢复实现，保留复制操作。

宿主 `make test` 与官方仓库测试、构建覆盖会话授权/撤销、请求形状、热键冲突/所有权、持久化恢复、去重/淘汰、摘要、全文搜索、删除/清空和预览预算。Windows/Linux 交叉编译只能验证代码构建，不等同原生剪贴板、热键、焦点或自动输入验收。未运行真实桌面验证，也未发布商店记录。


## 后续调整：辅助功能权限引导（2026-11-14）

按用户要求，显式请求粘贴且缺少 macOS 辅助功能权限时，宿主在 AppKit 主线程显示原生引导弹窗，提供「打开系统设置」与「稍后」。前者打开固定的辅助功能设置 URL；无法打开时给出手动路径。目标应用关闭与缺少权限现在分别返回错误，只有缺少权限会排队弹窗；不在启动、监听或普通复制时提示，不自动修改系统授权。

同一时间只允许一个引导弹窗，排队后再次核对视图及会话；已撤销页面不弹窗。弹窗期间沿用原生对话框的失焦隐藏抑制，桥接请求不等待用户选择。开启后用户重新选择条目粘贴，已复制内容保留。新增无界面测试覆盖错误分流、去重、关闭后重试与会话撤销；未运行真实弹窗或设置跳转验证。第三方页面未获得任意 URL 打开或对话框 API。
