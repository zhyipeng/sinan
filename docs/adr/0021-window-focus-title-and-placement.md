# ADR 0021：复用窗口聚焦、标题与鼠标屏幕定位

- 状态：macOS 开发入口已实施，跨屏实际行为待人工复验
- 日期：2026-11-06

## 原因

搜索和管理入口此前对重复打开只返回错误，窗口标题固定，首次定位也不考虑鼠标所在显示器。需要复用仍有效的客体，保留其输入和当前位置，并使窗口归属清晰。

## 决策

- 控制器记录启动中/已运行的客体。相同插件/视图的命令、命令别名和管理入口共用记录；启动中等待同一次启动完成，已运行则请求聚焦，不重载页面或创建第二个进程。
- 内核增加不分配会话槽位的描述解析：验证当前声明、启用状态、包指纹并返回绑定。复用前比较绑定且要求原会话仍活动，因此满额时仍可聚焦；新建时再次准备会话并比较绑定，若准备期间包发生替换则拒绝，不能用相同指纹复活旧句柄。
- 私有客体管道新增宿主 focus 控制和客体 focused 确认，控制编号单调递增，确认只允许匹配当前待处理请求；伪造、重复和越界结构拒绝。最多一个待处理控制，无无限队列。页面桥仍只能 ready/close，不能发送原生聚焦确认。
- 原生主事件循环取出控制后恢复最小化窗口、显示、激活并把焦点交给 WebView，再返回确认。聚焦保留页面、输入和窗口位置；新窗口才进行初始定位。
- 2 秒聚焦等待超时只返回错误，不撤销健康窗口；保留一个有界待确认项，接受迟到确认后恢复后续聚焦。尚未确认时拒绝追加控制。撤销/退出会立即结束等待；会话失效后不再处理新控制。跨进程撤销仍有异步传播窗口，不宣称 OS 焦点与内核状态构成原子事务。
- 对宿主已发出请求的确认不消耗页面/资源的 256 次请求预算；它们仍受序号、待确认关联和帧大小检查。非控制请求的原预算保持，否则正常反复打开会耗尽页面预算并丢失输入。
- contributes.uiViews 增加可选 title，最多 64 个 Unicode 字符，拒绝空白标题和控制字符。内核产生「插件名 · 视图标题」，省略标题时用插件名；插件名显示部分有界并过滤控制字符。标题随会话元数据传给固定客体，HTML 不能覆盖原生标题。管理组件使用可读标题，省略时回退 ID。
- 新窗口用原生 mouseLocation 与 NSScreen.frame 选择显示器，在 visibleFrame 居中，尺寸不超过该可用区域。坐标均为 Cocoa 逻辑全局坐标，支持负原点，不与 Wails 坐标混用。复用窗口不移动到当前鼠标屏幕，避免覆盖用户已调整的位置。

## 兼容与验证

后端 API 1 和页面 UI 桥版本保持。Manifest 的可选 title 对未声明它的包不产生要求，旧宿主仍会按未知字段拒绝新包。私有管道扩展要求宿主与客体一同构建；没有增加 Wails 或页面调用任意窗口的能力。

Go 竞态测试覆盖聚焦确认、撤销后拒绝、260 次确认不耗尽页面预算、聚焦超时不杀窗口、迟到确认回收、未请求的确认拒绝、别名/管理入口复用同一 PID、满会话槽位复用、元数据标题和标题校验。真实原生测试确认两次聚焦被主循环处理且页面输入未清空，既有故障探测继续通过。浏览器回归检查标题呈现并保留搜索打开和错误处理。

真实进程测试并行运行时在本机出现冷启动/调度超时；独立运行通过。make test 现以 -p 1 按包串行，保留竞态检测和产品超时，不以增大产品预算掩盖失败。内部进程夹具启动等待与既有 3 秒预算一致，生命周期测试留出启动时间。

## 限制

聚焦确认表示原生已处理显示/激活请求，不保证系统在所有全屏、Space 和焦点策略下立即切换。三屏、最小化恢复、拖动后复用和中文输入法仍按人工指南复验。未实现窗口位置持久化、尺寸声明、跨平台运行时或操作系统沙箱。
