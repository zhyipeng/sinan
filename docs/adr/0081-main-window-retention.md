# ADR 0081：主界面输入与插件 UI 的独立保留时长

状态：已实现，已随宿主 0.4.0 发行；真实桌面交互待三端实机验收。

## 决策与原因

用户要求设置增加「清除输入框延迟」「插件 UI 保留时长」，并确认两项默认均为 0 秒。设置插件在通用分类现有内容之后追加两个数字输入和保存按钮，整数秒范围 0–86400；保存后立即更新当前宿主策略，并在重启后恢复。内核使用独立保留命名空间 `$main-retention`，校验范围、结构和修订号，损坏记录保留并关闭保留行为，写入失败不更新运行策略。

两项计时都从主界面隐藏开始，重复隐藏不延长截止时间。输入延迟到期由宿主计时器定向通知 Shell 清空主搜索文字、粘贴预览及对应搜索；0 为立即清空。下次唤起会再次按隐藏时长核对，避免 WebView 后台暂停或消息延迟导致旧内容恢复。该配置不清除搜索使用频率记录，也不清空插件自身的表单或编辑器。

插件 UI 保留与输入保留独立。在期限内通过热键或托盘唤起时，不重置可信插件 React 树或同窗口原生隔离视图，会话、表单、内容和当前高度保留，并恢复视图显示与焦点；到期或配置为 0 时释放同窗口客体并返回主输入框。仅输入仍有效时，返回主输入框保留输入并重新搜索。UI 期限不会在隐藏后台自动关闭插件，而是在下一次主界面唤起时决定去留；插件运行时自身撤销、预算、异常和任务生命周期继续有效。

正在执行隐藏窗口任务、等待任务起动或跨应用粘贴的客体不走普通 UI 恢复，以免重新展示截图中的窗口或重入输入流程；显式返回搜索、打开设置或指定新命令沿用明确导航语义。拆出的独立窗口不参与主界面计时，新主窗口不继承其输入或隐藏时刻。

## 实现与平台边界

宿主将快捷键隐藏、失焦、关闭主窗口、插件 window.hide、隐藏窗口任务及跨应用输入的主窗口隐藏统一纳入计时；程序化展示会取消隐藏计时，避免可见期间被旧事件清空。每次隐藏、展示和时长修改都推进会话序号，取消计时器同时使已排队的旧回调失效；Shell 也按序号拒绝过期通知。修改隐藏中的时长从原隐藏时刻重新计算，已经清除的输入不会因延长设置而恢复。拆出和宿主退出取消计时器。

macOS、Windows、Linux 共用 Go 时钟与既有 Wails/React 导航及三端同窗口隔离承载，不新增平台 API、系统依赖或权限。Linux X11/Wayland 的快捷键、焦点和显示能力沿用既有适配限制。历史独立进程客体承载缺少可用的可见性时钟，不支持配置非零插件 UI 保留时长，保存时明确拒绝；本轮目标桌面构建均使用同窗口承载。

设置 UI 仍在 `system.settings`，内核只提供校验和持久化，Shell 保留宿主生命周期机制。不扩展公开插件协议、SDK、manifest 或商店格式；另外两个插件仓库不需要为本项联动。同期工作区中的跨插件交接改动独立于本决策，保留其最新实现和文档。

## 验证

无界面测试覆盖两项默认值和独立截止时间、精确到期边界、重复隐藏不续期、重新唤起和拆出取消旧会话、旧回调失效、延长设置不恢复已删除输入、关闭及计时器重排，以及配置持久化、非法值、旧修订、损坏记录保留和磁盘失败。宿主测试不创建原生窗口。具体平台构建结果见跨平台文档；未执行真实桌面、原生 WebView、焦点或快捷键手工验收。
