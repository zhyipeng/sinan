# ADR 0049：所有内置插件禁止禁用与卸载

- 状态：已实施
- 日期：2026-11-12

## 原因

用户要求所有内置插件均不可禁用和卸载。此前宿主仅保护设置和插件管理，应用检索仍按普通插件处理。

## 决策

- 宿主保护集合固定包含当前三个内置身份：`system.app-search`、`system.settings`、`system.plugin-manager`。不按 `system.*` 前缀泛化，也不允许 manifest 自行设置保护标记。
- 内核的 `SetPluginEnabled(false)`、`Uninstall` 与 `UninstallChecked` 均执行同一保护规则。拒绝操作不更改包、运行状态或配置。
- 继续通过 `PluginInfo.protected` 向可信界面提供只读元数据；已安装与发现页均隐藏内置插件的禁用和卸载操作。既有商店覆盖保护同样适用于应用检索。
- 读取有效历史禁用列表时忽略三个内置身份，其他插件的禁用状态保持，不主动重写原始配置。损坏配置仍遵循默认拒绝策略，不绕过错误恢复。
- 停止、重载、升级及原有恢复能力保留。原生应用检索不加入仅接受设置和插件中心声明包的系统视图修复白名单。
- 已合并退役的 `system.plugin-store` 不再属于当前内置集合，其按已知内容指纹清理的迁移流程保持。官方仓库中的普通工具插件仍可禁用和卸载。

## 验证

无界面回归覆盖全部内置插件安装后的保护元数据、拒绝禁用及两种卸载、拒绝操作不改变策略或包、历史禁用记录兼容及普通插件仍可禁用卸载。应用检索使用真实声明与不执行的占位后端安装，不启动桌面或扫描应用。真实 UI 验收未执行。
