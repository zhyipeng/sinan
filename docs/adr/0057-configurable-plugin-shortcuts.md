# ADR 0057：宿主统一配置插件快捷键

日期：2026-11-14。状态：已实现；无界面验证，真实 UI 未验收。

## 决策

用户要求剪贴板热键可配置，并集中在设置界面。保留插件命令的 `shortcut` 作为默认值；所有声明了热键的有效 HTML 视图命令，统一由桌面宿主管理注册、用户覆盖、冲突检查、录入和生命周期。界面放在 `system.settings` 已有设置项后面的「插件快捷键」，复用现有组合键录入、恢复默认和显式保存组件。不让各插件自行创建热键设置，也不向隔离页面增加修改宿主配置的接口。

用户覆盖按插件 ID / 命令 ID 保存在保留的 `$plugin-shortcut/<pluginId>/<commandId>` 命名空间，各命令有独立修订号；与 `$launcher`、`$window`、业务插件配置和历史数据分离。沿用现有设置文件与命名空间数量预算，保存失败不绕过预算。重新启动、重载、升级及卸载保留覆盖；重新安装相同身份可恢复。清单默认变化更新恢复默认目标，已有覆盖继续优先；「恢复默认」填入当前默认值，保存后生效。

## 注册与录入

每个插件热键复用宿主 shortcutController。保存新组合时先注册，再释放旧组合和持久化；注册失败保留旧组合，存储失败回退注册，回退失败沿用已有明确错误提示。保存时双向检查与呼出、窗口独立及其他插件快捷键的冲突，OS 注册仍做最终判断。不把冲突组合描述为已生效。

只有已启用、无需补信任、包未变更且仍声明该命令的插件出现在列表。禁用、卸载或删除贡献时释放绑定并移出列表，协调间隔一秒；恢复后重新加载覆盖。启动冲突保留设置项和错误，后续协调可重试。录入期间已有插件全局热键和主呼出热键均转为定向捕获事件，避免触发打开或隐藏；结束、失焦或退出录入时恢复原动作。

后端服务仅绑定可信 Shell：列出插件热键、按身份与修订保存。UI 桥版本、清单热键字段、原生信任、隔离和 OS 权限边界不变。辅助功能引导仍由宿主处理，与热键配置分离。

## 验证

无界面测试覆盖默认注册、配置持久化、重建宿主后恢复、禁用/卸载释放、重新启用、过期修订拒绝、OS 冲突、写入失败回退、宿主与插件的双向冲突、录入不触发插件、启动冲突恢复和保留命名空间隔离。前端类型检查、构建及宿主日常回归验证；不运行真实桌面或浏览器交互，不将其等同全局热键实机验收。
