# ADR 0036：默认启用插件界面

日期：2026-11-11。状态：已实施，无弹窗检查通过；真实 UI 未验收。

## 决策与原因

用户在已安装 HTML 插件后遇到“独立插件窗口尚未启用”，要求修改。项目创建与安装流程已经开放，历史默认关闭的 UI 开关导致普通启动无法使用已安装界面。

将宿主 `-plugin-ui` 默认值改为 true，保留 `-plugin-ui=false` 作为显式排障关闭选项；`make dev-ui` 改为 `make dev` 的兼容别名。不迁移插件安装目录或数据，不改写插件启用策略。默认启用只是准备 UI 控制器，页面仍由用户命令按需打开，不在启动时执行所有插件。

## 边界与影响

- 当前原生承载仅支持 macOS；helper 仍从宿主可执行文件同目录加载，应用包内也需随宿主携带。
- 平台不支持或控制器初始化失败时，打开界面返回已有具体诊断；显式关闭时提示移除关闭参数重启。
- 隔离探测 `-ui-probe` 仍不创建普通 UI 控制器；独立临时验收保持既有行为。
- 独立客体、无完整 Wails Bridge、会话绑定和撤销、资源预算、后端 API 1、UI 桥 2、原生安装信任及延期权限系统均不变。
- 同步更新当前使用文档与新项目模板；历史 ADR 的默认关闭记录作为当时决策保留，由本文覆盖。官方插件说明兼容新旧宿主。

## 验证

`make test`、`make build` 和两个相关仓库的 `git diff --check` 通过。构建后的 `./bin/sinan -h` 无界面执行通过，确认 plugin-ui 默认 true，且记录显式关闭用法。未启动真实桌面、原生 WebView 或浏览器交互验证。
