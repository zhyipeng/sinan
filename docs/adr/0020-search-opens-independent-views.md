# ADR 0020：搜索命令打开独立视图

- 状态：开发期入口已实施，沿用默认关闭的独立窗口开关
- 日期：2026-11-06

## 原因

用户已确认独立窗口验收通过。仅从插件管理打开视图不适合日常使用，需要在搜索选择命令后直接打开，同时保留可信组件与第三方 HTML 的承载边界。

## 决策

- Manifest 命令增加可选 `uiView`，必须引用同插件的 contributes.uiViews ID，禁止同时声明非空 message、view 或 execution。原有 view 仍只代表静态可信组件，不自动转换为 HTML 入口。
- 声明式和进程插件均可贡献独立视图命令。内核普通 Execute 拒绝此类命令，不执行后台命令、不返回空的声明式结果；单纯打开 UI 不激活原生后端。既有 Search Provider 仍按搜索声明独立激活。
- 可信 Shell 新增 OpenPluginCommand(pluginId, commandId)，不接收视图 ID、入口、查询、脚本、权限或可执行文件。Manager.OpenUICommand 在同一变更锁中解析当前实例的命令绑定并准备会话，避免升级/重载时使用旧视图映射。
- 窗口控制器先准备有实例/指纹绑定的会话，再按实际插件/视图预留槽位。搜索命令、命令别名与管理入口共同去重；重复请求只撤销新建的临时会话，不影响原窗口。启动失败和宿主关闭均释放预留。
- 前端选择 uiView 命令后直接调用独立窗口接口，不进入可信组件或工具表单。启动成功才隐藏面板；失败保留搜索与固定错误。若启动期间用户重新呼出面板，迟到结果不能再隐藏新面板。
- 搜索的输入或动态结果 input 当前不传给页面。UI 桥仍为 ready / close；没有新增参数通道、页面调用后端能力或权限。独立 UI 命令暂不记录成功动作历史，与现有可信视图入口一致，后续统一设计。
- 临时验收包将说明命令改为「窗口验收」视图命令，用真实声明和同一入口复验搜索回车打开，不安装到日常实例。

## 兼容与限制

后端 stdio API 1 与 UI 桥版本不变。旧插件无需修改；旧宿主通过未知字段拒绝包含 uiView 的包，不会回退为执行后台。Schema 检查字段形状与混用，Go 额外检查所引用的视图存在。

仍需要 -plugin-ui 或临时验收模式，未开启时明确拒绝，不退回普通执行。同一视图已打开时暂返回已打开错误，不新增聚焦旧窗口的控制协议。未实现查询参数传递、通用权限授权、CPU/内存硬配额或操作系统沙箱。

## 验证

- Manifest 测试覆盖声明式/进程视图命令、缺失引用、非法引用与混用。
- 内核测试覆盖普通 Execute 拒绝、停止后的进程插件打开 UI 不激活后端、禁用/文件变化拒绝以及升级改变绑定后的当前视图解析。
- 冷启动实测约 2 秒，控制器测试启动等待与既有 3 秒预算对齐；等待搜索进入测试夹具的辅助函数包含首次 Execute 激活，按其 5 秒调用预算等待，既有独立响应延迟断言保持不变。
- 真实子进程测试覆盖命令与管理入口/命令别名共同去重，拒绝重复请求后原窗口仍有效，关闭后可重新打开。
- 浏览器回归使用真实 Shell 与模拟 IPC，覆盖搜索回车、开发开关拒绝、只提交两个身份参数、启动失败保留查询、成功隐藏、迟到结果不隐藏重新呼出的面板，并保留可信组件和直接动作回归。
