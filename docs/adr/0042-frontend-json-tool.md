# ADR 0042：官方 JSON 工具改为纯前端

日期：2026-11-12。状态：源码替换及无界面验证已完成，真实 UI 验收未执行。

## 决策与原因

用户要求删除官方插件中的旧 JSON 格式化实现，重做“JSON 工具”，首先满足格式化；后续明确选择 `vanilla-jsoneditor`。本次在 `sinan-official-plugins/plugins/json-tool` 原位替换，移除 Go 后端、格式化命令 RPC 与旧文本域页面。

保留插件 ID `tools.json`、打开命令 `open`、视图 `editor` 和 `{text}` 私有草稿结构，版本升至 0.2.0。运行时改为 `declarative`，仅打开 HTML 页面；不携带后端可执行文件，不声明后端命令。格式化和压缩在隔离页面本地运行。包为平台无关 ZIP。

## 界面与数值

使用 `vanilla-jsoneditor` 3.13.0 的文本模式，提供格式化、压缩、错误提示和快捷键；当前不开放树形、表格、查询等业务。`lossless-json` 4.3.3 同时供编辑器和格式化函数使用，保留大整数、小数精度和指数原始写法。重复键拒绝处理，避免覆盖丢失。格式错误保留输入。

草稿继续走 UI Bridge 2 的私有 storage，使用 revision 核对；写入期间的后续编辑串行保存，冲突后暂停写入并保留当前输入，由用户显式载入旧草稿。没有引入浏览器持久存储作为替代。

## 隔离与兼容影响

第三方页面仍使用原隔离 WKWebView，不进入可信 DOM，也不获得完整 Wails Bridge。仅保留 storage 声明，无后端执行白名单、网络、任意文件能力或新宿主 API；宿主协议及 CSP 不变。

上游库将组件样式注入内联 style，原样打包不符合宿主 CSP。插件构建阶段按锁定版本的 AST 提取这些 CSS 为本地资源，并让 CodeMirror 在 Document 上使用 constructed stylesheet。需要 Safari 16.4+ 对应的 WebKit；没有调整宿主 macOS 最低部署版本，因此旧系统可能无法使用本插件。依赖升级时必须重新核对适配，不声称本次完成了真实 WebKit 验证。

构建按 ESM 分块，检查每个资源不超过 512 KiB、UI 总量不超过 2 MiB、文件数不超过 128。当前资源约 1.32 MB，无 CDN。插件目录仓库同步名称和简介，仍为 pending-release，不新增可安装版本或虚构发布资产。

## 验证

- 官方仓库 10 项 Node 业务测试通过，覆盖格式化、压缩、错误、数值精度、旧草稿、并发保存和冲突恢复。
- 构建与平台无关 ZIP 打包通过，资源预算检查通过；宿主 UI 资源快照加载和临时目录 CLI 安装通过，无诊断错误。
- 按项目规则未启动桌面、原生 WebView 或浏览器回归。旧原生 JSON 测试夹具依赖 textarea 的交互方式，不能据此证明新版编辑器已通过原生交互验收。
