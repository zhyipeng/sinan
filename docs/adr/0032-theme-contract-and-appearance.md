# ADR 0032：主题契约与外观切换

日期：2026-11-11。状态：已实施首版。

## 背景与决策

用户要求浅色、深色、跟随系统，并为将来的主题插件预留接口。外观选择仍放在 system.settings 插件，追加在两个快捷键设置之后；宿主提供持久化、主题解析及窗口呈现机制。

默认跟随系统，选择保存到宿主配置命名空间 `$appearance`，使用独立 revision、冲突检测与原子写入。失败不改变已保存选择；非法记录退回系统外观并显示错误，保留原记录且禁止直接覆盖。

主题协议 v1 是数据契约：ThemeDefinition 提供 ID、名称、明暗分类和固定 18 个语义颜色。颜色只接受完整 `#RRGGBB`；不接受任意 CSS、URL 或脚本。ThemeState 提供模式、revision 和两套调色板。Registry 按提供者命名空间批量校验、注册并复制数据，作为未来主题贡献入口；本轮仅注册两套内置主题，没有主题插件清单、安装或动态加载能力。

可信 Shell 和隔离 HTML 共用宿主维护的被动呈现运行时，通过 CSS 自定义属性使用颜色。系统模式监听 prefers-color-scheme；SDK 提供 currentTheme / onThemeChanged 只读快照。HTML 客体通过私有父子管道收到初始主题及更新，不新增页面桥调用，不放宽 CSP，不暴露 Wails Bridge。自定义插件页面需要主动使用这些变量才能适配，硬编码颜色不会自动转换。

变更应用于已有文档，不重载页面、不撤销会话，不改变查询、草稿或拆窗身份。迟到的旧 revision 被忽略。macOS 原生窗口同步 Aqua / DarkAqua / 系统外观；其他平台的原生窗口能力仍受既有实现范围限制。启动时在 Wails 调度器初始化前读取系统偏好，不能提前调用 InvokeSync。

## 兼容与影响

主题版本独立于 stdio 后端协议和页面桥 1 / 2，这两者版本不变。父子宿主私有帧新增 theme 数据，桌面主程序与 sinan-ui-host 应一起重新构建。权限系统继续暂缓；被动主题数据不是授权功能。

后续可基于现有数据契约增加插件清单贡献、主题发现及选择，仍需单独处理加载、卸载回退和兼容，不把 Registry 预留接口描述为完整主题插件系统。

## 验证

无界面检查覆盖保存/重启、冲突和写失败回退、非法配置保留、注册命名空间/颜色校验/复制隔离、系统与手动切换、迟到快照、父子进程更新及会话保留。执行前端构建、Node 被动运行时测试、Go 竞态测试及构建，不启动真实 UI。真实系统切换、窗口标题栏和视觉效果留待用户明确要求的交互验收。
