# ADR 0047：统一默认窗口尺寸

日期：2026-11-12

状态：已采纳

## 背景与决策

按用户要求，将主输入面板宽度调整为 800 DIP，结果窗口最大高度调整为 600 DIP。空输入保持 50 DIP 高度，结果较少时仍按内容增长，结果区超出可用高度时滚动。

插件 UI、可信插件页及拆出窗口默认统一为 800×600 DIP；插件页采用固定高度与可滚动内容区，隔离 HTML 内容区扣除 58 DIP 可信页头后为 542 DIP。这替代 ADR 0040 中主面板内容区最多 430 DIP 的尺寸约定。原生 helper 普通窗口同步使用新尺寸，专用隔离探测窗口尺寸保持原值。

## 影响与验证

保留主面板的屏幕可用区域约束、顶部定位和拆出后的尺寸调整能力。拆出仍保留原有 WebView 与页面状态，无协议、权限或隔离边界变更。

更新多显示器居中及嵌入内容几何回归，通过无界面的 `make test` 验证；本轮不执行真实桌面、浏览器交互或手动验收。
