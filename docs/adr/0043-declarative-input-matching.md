# ADR 0043：通用声明式输入匹配与视图打开参数

日期：2026-11-12。状态：已实现，无界面回归通过，真实桌面交互未验收。

## 背景与决策

用户要求主输入框为 JSON 时显示 JSON 工具，并将内容带入编辑器；匹配规则须通用，支持正则且控制性能，JSON 插件仅识别对象和数组。继续保持该插件纯前端，不引入只为识别 JSON 而启动的后端，也不在 Shell 中写死 `tools.json`。

命令新增可选 `inputMatchers` 数组，规则为 OR 关系。宿主匹配机制支持 `regex` 与 `json` 两类：正则可表达 URL、前缀、文本格式等条件；JSON 规则要求完整合法 JSON，并显式指定顶层类型。匹配不激活插件，不运行插件 JavaScript。JSON 业务的类型选择由官方插件清单声明。

普通命令（含 native / direct）可复用输入匹配；HTML 视图须为桥 2。可信组件 `view` 尚无此输入契约，不支持；`searchOnly` 仍专用于动态 Provider，不与该声明混用。名称、关键词与拼音搜索继续保留。内容匹配结果与该命令的普通结果合并，默认分数 .95；不修改既有精确名称分数 1、普通匹配 .85 或 Provider 分数上限 .8。

## 性能与资源边界

- 原始查询最多 64 KiB，长度条件均按 UTF-8 字节计；不合法 UTF-8 不参与内容匹配。超过上限返回空结果。名称/拼音搜索和动态 Provider 仍只处理不超过 4096 字节的去空白查询，大文本仅走声明式内容匹配。
- 每命令最多 8 条、每插件最多 32 条匹配规则；每次搜索累计最多评估 256 条。达到预算后跳过剩余内容匹配，名称搜索仍可继续。按宿主快照中的命令顺序评估。
- 正则仅支持 Go/RE2 语法，默认子串匹配，完整匹配由 `^` / `$` 声明。允许 `(?i)` 等 RE2 内联标志，不支持反向引用或前后查找。避免回溯式 ReDoS。
- 每条正则最多 256 字节、编译后最多 256 条 RE2 指令；构建清单实例时校验，进程内以最多 256 条 FIFO 缓存复用编译结果，缓存不保留用户输入。
- 每次搜索的正则累计工作量以“输入字节 × 编译指令数”估算，最多 8,388,608；不足时跳过该正则，不截断输入、不误判为命中。该预算不是严格毫秒级实时保证。
- 一次搜索最多执行一次 JSON 语法检查，后续规则复用顶层类型；只检查语法，不经浮点转换，也不序列化或改写原文。禁止在结果标题、日志或缓存中追加原始正文。
- 继续沿用查询取消和旧结果丢弃机制。当前预算可能导致大量已安装规则靠后的内容入口未显示，后续可依据真实使用数据调整。

## 打开参数与隔离

新增可信 Shell 绑定 `OpenPluginCommandWithInput` 和内核 `OpenUICommandWithInput`；旧无参数接口不变。用户选中结果后才创建带输入的新会话，附着与 helper 路径都不复用已有编辑器，从而不吞掉新输入或覆盖已拆出页面。

UI Bridge 2 增加只读 `launch.get`，SDK 为 `readLaunch()`，返回 `{commandId?, input?}`。参数捕获于当前 Session 的内核调用闭包，身份、实例、包指纹、就绪、撤销和调用预算继续校验；不接受页面提交插件 ID、路径、替代输入或额外参数。读取打开参数不授予 storage 或后端调用能力。HTML 页面不能订阅主输入框，也没有新增完整 Wails Bridge、全局输入事件或 URL 参数。桥 1 行为不变，带参数打开桥 1 被拒绝。

`input` 省略表示普通打开；显式空字符串表示传入空内容。原文的空白、数值和字符保留。输入最多 64 KiB，JSON 编码后的打开参数还须满足原有 192 KiB 返回预算；过度膨胀的控制字符数据在创建会话前拒绝。

协议为 API 1 / UI 桥 2 的增量扩展；旧清单继续可用，旧宿主会拒绝带新清单字段的插件，不能声称新版插件可在旧宿主上实现本功能。

## 官方插件接入

官方 `tools.json` 升至 0.3.0，声明 `{"kind":"json","jsonTypes":["object","array"]}`；基础值、非法 JSON、尾随内容均不触发该内容入口，原有名称搜索保持。

打开参数优先显示，普通打开恢复草稿；实际编辑、格式化或压缩后才保存，避免仅打开结果就覆盖旧草稿。草稿仍受原有单文档 32 KiB 限制，大文本可编辑但不保证能保存。SDK 快照为记录的基线提交加可重放的本地补丁，文件与补丁摘要均更新，不虚构来源提交。目录仓库保持 pending-release，无新增发布记录。

## 验证

- `make test` 通过：前端类型检查/构建、主题 SDK 测试、Go 竞态回归；新增匹配、清单限制、参数原文/空值/大小、跨会话隔离和撤销测试。
- 官方插件 12 项 Node 业务测试及 0.3.0 ZIP 打包通过；SDK 补丁从基线重放后与快照字节一致。
- Apple M4 Max、darwin/arm64、64 KiB 输入、300 ms Go benchmark：`^(a+)+$` 拒绝尾随非匹配字符约 1.48 ms/op；JSON 对象校验约 0.111 ms/op。这是单规则微基准，不是整个搜索链路或 P95 保证。
- 真实官方插件包在临时目录完成安装、宿主资源快照、内容匹配、带原文创建会话、读取打开参数与会话撤销检查，未启动 UI。
- 日常验证未启动浏览器、原生 WebView 或桌面窗口。
