# ADR 0024：主窗口与独立页的局部事件

- 日期：2026-11-09
- 状态：采用
- 修正：ADR 0023 实现中的窗口事件投递

## 问题

用户反馈拆出后呼出主搜索框，独立窗口 UI 也随之改变。此前将 WebviewWindow.EmitEvent 当作定向投递，但当前 Wails 实现将事件交给应用事件总线；Sender 是来源名称，所有窗口仍会接收。launcher:show 因此重置独立页面，view:detached 也可能误改新主窗口角色。

## 决策

两类窗口局部事件均通过目标窗口的 DispatchWailsEvent 投递，保留设置、快捷键等跨窗口状态事件的显式分发。独立页面使用同步 ref 记录角色，在长期注册的 launcher:show 监听器中拒绝重置；从拆出事件及成功的拆出响应更新角色，不依赖闭包中的旧 React state。

本次不改变插件桥、权限或独立客体协议。

## 回归

新增 test:windows，使用真实 App、Wails 前端事件分发和确定性 IPC 夹具。先确认旧代码会将独立设置页重置为搜索，再验证修复后设置目录草稿和管理页目录草稿均保留；新主页面仍可清空查询、搜索并打开另一可拆出页面。浏览器夹具验证前端状态防护；定向投递方式同时按所用 Wails 源码确认。
