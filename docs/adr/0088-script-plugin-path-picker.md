# ADR 0088：官方脚本插件与原生路径选择

日期：2026-11-18。状态：已实现，待桌面实机验收和发行。

独立官方插件 `tools.script` 通过既有独立进程、Search Provider 和 HTML Bridge 2 提供解释器发现、自定义环境、脚本索引和运行。脚本目录、导入路径、所选环境和关键字保留在插件数据目录。宿主无需识别脚本格式或决定执行方式。搜索只返回插件索引中的脚本 ID，运行时再次校验文件和解释器。扫描直接子文件，避免遍历大型目录树。导入保留原文件，创建采用独占写入，避免覆盖同名文件。

隔离 HTML 的浏览器文件对象无法稳定提供原生路径，也无法打开系统目录选择器。因此增加可单独声明的 Bridge 2 视图权限 `file.pickPath`。页面只传 `file` 或 `directory`，宿主在当前会话所属窗口打开 Wails 单选对话框。选择成功只返回绝对路径；取消返回 null。没有调用者提供的任意路径、初始目录或宿主文件读写接口。继续使用会话撤销、单调用串行、常规频率和返回值限额，以及现有原生对话框超时。Wails 未提供统一的对话框强制取消接口，撤销或超时后的结果会被丢弃。

macOS 原生插件进程白名单加入宿主的 `PATH`，与 Windows 和 Linux 一致。发现不运行候选二进制，也不启动登录 Shell 获取额外路径。脚本以插件进程的当前用户权限启动，继承宿主已筛选的环境变量。执行传递独立的脚本路径参数，以脚本目录为工作目录；标准输出和标准错误不回传。后台脚本可独立完成，状态只保存在插件进程内。独立进程不构成操作系统沙箱。

三平台复用同一隔离桥和 Wails 对话框。Windows 直接执行使用 `.exe` 或 `.com`，Shell 脚本需可用的 `sh.exe` 或用户指定的适配解释器；类 Unix 平台直接执行要求执行位并允许系统处理 shebang。Linux 桌面入口依赖 GTK3/WebKitGTK，X11 与 Wayland 对话框需分别实机验证。

Go 校验器、JSON Schema、TypeScript 协议和 UI SDK 同步更新。脚本插件要求支持 `file.pickPath` 的配套宿主，已发布的 Sinan 0.5.0 不支持该声明。官方插件仓库记录 SDK 来源、补丁和摘要。商店协议无变更，待配套宿主和真实插件资产发布后登记。
