# ADR 0026：自定义窗口独立快捷键

- 日期：2026-11-09
- 状态：采用
- 补充：ADR 0022 / 0023 中固定拆出按键的机制

## 决策

设置页在呼出键之后增加窗口独立快捷键，复用录入、恢复默认和显式保存交互。macOS 默认 Command + Shift + D，其他平台默认 Ctrl + Shift + D；当前原生 HTML 客体仍仅在 macOS 验证。该组合只在当前插件页生效，不向 OS 注册为全局热键，也不声称检测其他应用的快捷键占用。

保存使用宿主保留的 $window 命名空间，与 $launcher 分开管理修订和持久化。校验标准组合格式，两个保存入口均拒绝呼出键与拆出键相同；旧窗口提交旧修订被拒绝，存储失败保留原设置。启动时若已有呼出键与默认/保存的拆出键冲突，设置页显示冲突，用户需重新选择组合。设置、插件管理和已打开的 HTML 客体使用同一配置。

可信页面订阅 detach-shortcut:changed 并丢弃较旧修订的初始化响应，按物理键码及修饰键匹配。录入控件消费按键，不触发拆出。捕获现有全局呼出键时，定向通知实际录入窗口，避免其他窗口的旧录入状态接收捕获。

私有 stdio 初始化增加可选 detachShortcut；运行中由父进程发送独立的 detach-shortcut 配置帧，未占用聚焦请求序号及页面消息预算。子进程缓存配置，原生层更新按钮提示和按键匹配，支持字母、数字、标准命名键和 F1–F20，忽略重复及输入法组词中的拆出事件。配置帧不是网页桥消息，页面仍只可发送 ready / close。

控制器启动完成后再次同步最新值，进程按父侧单调修订拒绝迟到的旧更新；管道写入不持有控制器锁，避免与原生 window-action 回调互锁。保存不迁移、不重新加载、不撤销已有页面。宿主与 helper 仍须同步构建、分发；私有协议扩展不是公共插件桥版本的升级。

## 验证

Go 回归覆盖保存持久化、独立命名空间与修订、双向按键冲突、无效组合、恢复默认、存活进程配置更新与旧更新拒绝；原生纯匹配回归覆盖默认、自定义、F19、方向及数字键和额外修饰键。浏览器使用真实组件验证两个录入控件、冲突保留、重新打开读取、恢复默认、旧键不触发及新键拆出，既有管理与搜索用例继续通过。

真实中文输入法、系统全局快捷键及全屏、多屏组合仍需手动验收。
