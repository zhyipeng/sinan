# ADR 0027：插件静态命令支持拼音检索

- 日期：2026-11-09
- 状态：采用
- 补充：ADR 0005，将通用文本转换从应用插件提为共享工具

## 背景

应用检索已有拼音及首字母别名，插件静态命令仅对插件名、标题、关键词做大小写无关的文字包含匹配，因此设置和插件管理无法通过 sz / cjgl 等方式找到。

## 决策

将已有别名生成与 macOS Foundation Mandarin-to-Latin / 去音调实现移入 packages/plugin-sdk/searchtext，应用插件继续调用同一算法，目录、索引、刷新和候选召回仍保留在插件层。宿主静态命令聚合器复用通用别名，覆盖插件名、命令标题及关键词，不从应用插件导入业务实现，不靠逐个手写关键词补齐拼音。

保留原始文字匹配、原始结果标题及命令身份；精确标题分仍为 1，其余静态匹配沿用 0.85，历史权重不变。动态 Provider 仍接收原查询并自行匹配，宿主不为动态结果建立拼音索引。禁用插件及 searchOnly 命令继续排除。

为避免每次按键重复原生转换，宿主按原文本缓存拼音别名，最多 2048 项，达到上限后清空再填充；超过 2048 字节的文本不保留。缓存仅针对含汉字的字段，使用锁保护且不持锁执行转换；重复冷查询允许重复计算。元数据变化使用新文本键，不会复用旧名称，缓存不落盘。静态扫描检查取消，避免已过期查询继续转换后续字段。

## 验证与限制

SDK 回归覆盖原文保留、去重、全拼和首字母；搜索聚合回归覆盖 shezhi / she zhi / SZ、chajianguanli / cjgl、标题和关键词别名、中文英文共存、精确排序、禁用及 searchOnly 排除、元数据变化和缓存容量。应用插件已有拼音、目录与快照测试继续通过。

拼音转换仍只在 macOS + cgo 提供，其他平台保留原文匹配；多音字依赖系统转换，不保证全部读音。本次没有改变插件协议、manifest 或权限。
