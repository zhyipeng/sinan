# ADR 0084：macOS 截图自定义选区遮罩

日期：2026-11-18。状态：已实现，实机验收与发行待完成。

0.1.0 在 macOS 将选区和采集交给系统截图工具，松手即完成截图。用户希望参考 [Snow Shot](https://github.com/mg-chao/snow-shot) 的选区体验，在确认之前可以调整范围。实现采用独立的 AppKit 遮罩和 ScreenCaptureKit，参考交互流程，自行编写实现。

截图 0.2.0 在 macOS 14+ 由独立官方插件的 Go 后端启动同架构的包内辅助程序。辅助程序在已隐藏 Sinan 的现有流程中分别捕获各显示器的一帧，然后在各显示器打开静态遮罩。鼠标所在的非激活面板首先请求键盘焦点，可以直接在另一块屏上开始框选并切换焦点。选区支持拖动定位、边或角调整大小、方向键像素级移动、像素尺寸提示、Esc 或右键取消。选区工具支持选中和拖动已有文字、箭头、矩形和马赛克，撤销按添加或移动的顺序回退。坐标按快照的实际像素尺寸映射，预览和 PNG 使用同一套标注渲染。单次选区限制在开始拖动的显示器，在另一块屏重新框选会清除原选区。macOS 旧版本继续使用系统区域选择。

框选后在遮罩显示选区、箭头、矩形、文字、马赛克、撤销、复制、保存和 OCR。复制通过辅助程序写 PNG 到系统剪贴板，保存使用辅助程序的 AppKit 保存面板，取消保存会回到遮罩。两项成功后结束隐藏执行会话。Return 和双击选区可快速复制。收尾留在平台辅助程序，免去重新呈现编辑器窗口，同时保留独立编辑入口。

OCR 可用时，辅助程序将含标注的 PNG 写入 Go 后端的私有临时目录，隐藏页面通过现有分块读取与插件交接能力打开 OCR。用户点击 OCR 后查询依赖，避免阻塞遮罩出现；开始跳转前显示带状态的宿主窗口，因为嵌入视图切换不会把隐藏窗口带到前台。缺少依赖或交接失败时显示原因，并在编辑器保留已标注图片，依赖缺失时提供插件中心入口。超过 4 MiB 在遮罩内提示。无公开协议、SDK 或宿主权限变化。

屏幕录制授权由 macOS 管理。快照限制单屏 3200 万像素、合计 9600 万像素，输出 PNG 继续沿用 3200 万像素、8 MiB 上限。Go 任务撤销时终止辅助程序，辅助程序监听 Go 父进程退出。屏幕布局变化或焦点离开全部遮罩面板时取消，原生保存面板打开期间保留会话。独立辅助程序并不构成系统权限沙箱。

macOS 构建需要 Xcode 命令行工具及 macOS 14 或更新的 SDK，辅助程序采用临时签名，打包器要求 macOS ZIP 包含匹配架构的 Mach-O 辅助程序。Windows 保留 WinForms/GDI，Linux 保留 X11 的 scrot 和受支持的 Wayland 的 grim/slurp。现有宿主、协议、SDK、WebView 隔离、编辑器和声明权限可复用，最低宿主仍为 0.4.0。新版本未登记到插件商店。

授权归属与升级后的授权保留、焦点、全屏 Space、多屏、Retina 实际渲染、输入法、剪贴板、保存面板及 OCR 实际跳转待实机验收。

macOS arm64 本机运行官方插件的 142 项 JavaScript、14 项 Python 和 Go 竞态回归，捕获组件通过 Clang 静态分析、合成选区坐标和 Retina 标注 PNG 检查，模拟宿主的 stdio PNG 传输及宿主包预览通过。六目标构建与打包通过，核对 macOS 两架构包内辅助程序的执行权限和临时签名。Windows 和 Linux 本轮仅交叉构建与打包。

快捷键链路的隐藏等待从实际隐藏时开始计时，与隐藏页面准备并行。已经隐藏的窗口免去重复等待，刚隐藏的窗口仍留出原有合成器缓冲。macOS 15.2+ 且构建 SDK 支持时，优先直接按显示器矩形捕获，返回尺寸不匹配或失败时回退到按显示器过滤捕获。遮罩工具条在首次框选后创建。Esc 初始焦点、快捷键实测耗时及真实 OCR 切换仍待桌面验收。

本轮 macOS arm64 宿主标准无界面回归与打包通过。Windows 两架构宿主测试交叉编译通过。官方插件无界面回归覆盖 OCR 可见性、依赖缺失和标注移动后的合成 PNG，截图六目标构建和打包通过。Linux 宿主未单独构建。
