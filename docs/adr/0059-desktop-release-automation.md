# ADR 0059：桌面宿主自动构建与 Release

日期：2026-11-14。状态：实现已接入，远端 Actions 和真实发行待验证。

## 决策与原因

用户明确要求仅为 Sinan 桌面宿主接入推送 `v*` 标签后的三平台构建与 GitHub Release。复用统一 Node 构建入口，通过可复用 Actions workflow 在六个 OS/架构原生 runner 上打包和执行无界面检查；全部成功后发布草稿中的完整归档与汇总 SHA-256。预发布不占用 Latest，已公开版本不覆盖。仅发布 job 使用仓库内容写权限，不需要额外个人凭据。

此前发行包缺少内置插件。构建时只生成三个插件的清单、图标和平台原生应用检索后端，通过 Go embed 随宿主发行。默认用户目录正常启动时，经既有内核 API 安装缺失的内置插件；原生信任仅适用于内嵌应用检索后端，不从可写相邻目录自动发现或信任代码。已有、损坏或开发安装不自动替换；初始化错误进入已有恢复提示。显式插件目录、探测与临时验收不触发初始化。

## 影响与边界

插件业务继续位于插件层，宿主只负责已知发行快照初始化；没有扩大第三方 UI Bridge、协议或普通插件权限。官方插件仓库和目录格式不变，无需联动修改另外两个仓库。随宿主内嵌不等于操作系统沙箱。

macOS 归档仅 ad-hoc 签名；Windows/Linux 为便携目录，不包含安装器、系统依赖或发行签名。既有插件升级沿用原流程，未引入后台自动更新。详见[发布流程](../releases.md)。

本地原生构建、无界面回归、归档验证与远端 Actions、目标机 UI 验收分别记录；配置六个 runner 不代表六个平台运行已经通过。

## 本轮验证

macOS arm64 发行打包、签名校验、归档与 SHA-256 检查、全量无界面回归、初始化故障/保留与真实内嵌快照测试、`go vet` 和 actionlint 通过。发布脚本覆盖无效标签、缺包和摘要不符的拒绝路径。Windows arm64 仅完成桌面测试程序交叉编译；远端原生矩阵、上传/重跑与 GitHub Release 公开流程未实跑，未启动桌面 UI。
