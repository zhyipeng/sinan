# ADR 0006：配置服务与可信设置插件

日期：2026-11-04。状态：首版已实施，仅验证 macOS arm64。

## 职责

新增 `system.settings` 声明式插件，贡献“设置”命令。界面代码位于 `plugins/system-settings/frontend/`，通过搜索打开；应用检索插件声明自己的设置项。内核提供命名空间配置读写、校验、版本迁移、原子替换、修改冲突检测与进程生命周期控制，不包含应用目录表单。

首版配置类型仅为 `directory-list`，不是完整 JSON Schema 表单系统。每插件最多 16 项，每项最多 16 个目录；写入时检查绝对路径、长度、存在性及目录类型，并去除重复路径。空列表表示没有额外目录；标准应用目录保留。

## 配置存储

配置文件为插件根目录下 `.sinan-state/settings.json`，整体版本为 1。旧的无版本同布局视为版本 0，内存迁移后在下次成功写入时保存版本 1。未知版本、损坏文件、未知顶层字段或超过 1 MiB 的文件保留原样并阻止写入，插件运行和宿主恢复入口仍可使用默认配置。

保存用 0700 目录及 0600 临时文件，原子替换，失败不更新内存 revision。每个插件命名空间单独递增 revision；过期写入会报错，不静默覆盖较新的设置。卸载插件保留宿主配置，重新安装时恢复；删除设置插件不影响配置服务。当前仍是有界 JSON，尚无 SQLite、通用插件数据存储或跨进程锁，同一根目录应由一个宿主实例写入。

配置文件可以包含用户指定的目录路径；不会把这些路径或文件内容写进诊断日志。此处不支持存储凭据，也不提供 OS 沙箱。

## 协议与应用

API 1 新增可选字段：

- Manifest `contributes.settings`：`id`、`title`、`type: "directory-list"`。
- Manifest Command `view`：声明式视图命令与 `message`、`execution` 互斥。
- `initialize.params.settings`：宿主只提供当前插件的配置键值；未声明键不会提供，缺失项默认为空列表。旧 SDK 忽略可选字段，当前 SDK 增加初始化回调。

保存配置后，宿主只停止受影响插件的进程；下次调用重新握手并应用新快照。在途调用可能失败，旧实例的迟到结果不会视为新实例结果。其他插件继续运行。当前没有插件反向 Host API，也没有配置热更新通知协议。

可信 Shell 成功保存后收到定向 `settings:changed` 事件，只含插件 ID 和 revision，不广播配置内容。设置组件直接使用保存响应更新状态。应用检索 0.3.0 在初始化时将额外目录加入标准扫描范围，沿用深度、数量、去重和索引限制。

CLI 提供 `settings ID`、`set-settings ID revision JSON`；修改或清除历史前须退出使用同一根目录的桌面实例。桌面设置页的历史清除通过当前宿主内存和存储服务同时生效，无需退出桌面。

## 可信组件边界

设置组件随宿主构建，Shell 静态注册 `system.settings/settings`，并传入仅含读取配置、保存配置和清除历史三个方法的适配器。安装目录中的 JS、HTML 和资源路径不会被导入或执行。Manifest 的 `view` 只是打开预先注册组件的请求；声明相同 ID 不会使安装包中的代码获得可信身份。

未知视图键显示错误，不回退到任意文件加载。此实现允许仓库维护的可信组件按插件组织，不是公共第三方 UI 加载器，也不改变 ADR 0003 中尚未解决的导航、资源和渲染故障边界。修改可信组件仍需重建宿主。

## 验证

- 存储及竞态测试：命名空间、深拷贝、持久化、文件模式、同 revision 并发写入、迁移、未知版本/损坏文件保留、写入失败回滚。
- 真实进程测试：只重启受影响插件、初始化传入配置、其他插件 PID 保持、非法目录/未知键拒绝、重新安装恢复配置。
- 浏览器使用实际 Shell 和设置组件、模拟 IPC：搜索进入设置、无效输入错误、保存归一化、返回后重开读值、历史清除；同时回归默认选择、手动选择、慢结果及直接执行。按 680 DIP 窗口宽度检查布局。
- 实际 CLI 与应用插件进程验证：二进制 plist 测试应用在默认扫描范围外不可见，保存目录后可检索，清空后消失；配置目录本身为符号链接时仍能扫描且保持入口 ID。
- `make test`、`go vet ./...`、前端类型检查与 `make package` 通过；后续链接路径修正另通过应用插件竞态回归。

首版不包含通用布尔/数字/敏感配置、自定义复杂页面动态安装、插件侧热更新、文件选择器或完整设置管理能力。
