# ADR 0090：宿主后台更新与下载进度

日期：2026-11-18。状态：已实现，真实桌面验收待补。

用户要求本体更新显示下载进度，并在主窗口隐藏时继续下载。

- 可信窗口的安装调用只负责授权和提交。设置插件在启动后台任务前锁定更新状态，阻止并发检查或重复下载。任务使用应用级上下文，设置页关闭、视图重新挂载及主窗口隐藏均不取消任务。应用退出后不保留下载进度。
- 下载器将成功写入文件的字节数记入线程安全的内存快照，以 GitHub 发行元数据中的资产大小为总量。可信设置页定期读取下载进度，页面挂载和窗口恢复时重新读取。阶段通知与任务执行分离，慢速或隐藏的 WebView 不会阻塞下载。
- 下载、准备安装和退出安装分别呈现。长度和摘要校验、解包检查及助手就绪后自动重启沿用 [ADR 0060](0060-host-auto-update.md)。失败后设置页显示错误，允许用户重试。

三端共享 Go 更新任务与 React 进度界面，沿用各平台的安装助手。仅更新可信 Wails 绑定，公开插件协议、SDK、权限和发行资产格式维持原有契约，两个插件仓库无需联动。验证范围见[跨平台适配](../cross-platform.md#宿主自动更新)。
