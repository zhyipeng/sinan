# ADR 0085：macOS 截图智能选区

日期：2026-11-18。状态：已实现，实机验收与发行待完成。

用户要求在现有多显示器截图遮罩中同时支持整窗和窗口内元素吸附。已授予 macOS 辅助功能权限时默认使用元素模式，未授权时使用整窗模式。遮罩先显示光标下最靠前窗口的轮廓，单击将其设为当前选区，拖拽超过点击阈值进入自由框选。显示器之间共享吸附模式。跨屏窗口和元素均裁剪到光标所在显示器，确认后复用现有的调整、标注和输出流程。

整窗模式在后台异步枚举一份当前可见窗口的屏幕范围，按窗口层叠顺序命中，并排除截图进程自身、桌面层和高层系统窗口。遮罩呈现不等待枚举。遮罩启动时静默检查 macOS 辅助功能权限。按 Tab 切换模式，从窗口模式切到元素模式且缺少授权时请求系统提示，并保留整窗选取。授权由系统处理，授权归属和升级后权限保留待实机核对。

启用元素模式后，按命中窗口所属应用做辅助功能坐标查询。只读取元素和有限上级的坐标、大小及父级引用，不读取标题、值或文本，不执行辅助功能动作。查询在后台去抖，设置 IPC 超时并丢弃迟到结果。滚轮切换候选范围。目标应用未返回有效边界、查询超时或不可用时沿用整窗候选。元数据仅驻留在本次截图进程。

实现位于官方截图插件的 AppKit 辅助进程，沿用现有 ScreenCaptureKit、宿主协议、插件声明和最低宿主版本。Windows、X11 和 Wayland 延用各自现有截图适配，后续平台适配应分别评估窗口枚举和辅助功能权限。尚未发行或登记商店。

macOS arm64 无界面回归、窗口层叠命中、跨屏裁剪和坐标映射测试通过，新原生代码通过 Clang 静态分析，截图六目标构建及打包通过。真实辅助功能授权、应用元素命中、焦点、滚轮和多屏交互未实机验收。
