# ADR 0048：插件管理与商店合并为插件中心

- 状态：已实施；无界面回归通过，真实 UI 尚未验收。
- 日期：2026-11-12

## 原因

插件管理与商店分别维护入口和界面，用户需跨页完成安装、更新和日常管理。用户确认合并为一个内置插件。

## 决策

- 保留 `system.plugin-manager` 身份，名称改为「插件中心」，版本升为 0.7.0。沿用唯一 `open` 命令与 `manager` 可信视图，以关键词兼容「插件管理」「插件商店」和原有英文搜索。
- 默认进入「已安装」，包含本地搜索、插件列表与详情；「发现」按需加载目录，提供浏览、安装与手动版本更新。共用详情组件和管理操作，商店内已安装插件也可启停、重载、卸载和打开。进入已安装页不要求加载远程目录，目录请求期间可返回已安装页。
- 本地目录 / ZIP 安装收进顶部「本地安装」，创建插件、私有数据清理和恢复入口归入「更多」。沿用现有主题、主窗口页头、返回与拆出机制。
- 商店目录契约、服务和 UI 移到 `plugins/system-plugin-manager`；移除独立商店 manifest、可信视图注册及开发安装步骤。宿主保留类型化适配器，下载、解压、信任、指纹校验和升级回退机制继续复用原实现。
- 插件中心沿用管理插件的禁止禁用、禁止卸载和宿主恢复规则。不新增第三方 API、权限或页面桥能力；目录签名等原有限制保持。

## 已有安装迁移

普通桌面启动时调用插件层迁移，探测和临时验收模式不调用。仅对已知 0.6.0 管理包和 0.1.0 商店包的完整内容指纹（源码目录安装与 manifest/icon 最小包）自动迁移。

1. 将已知旧管理包通过现有检查 / 应用事务升级到内嵌的插件中心最小声明包；仅安装过商店的实例先安装插件中心。空安装目录保持原样。
2. 确认插件中心声明可用后，移除已知旧商店包。新增内核内部 `UninstallChecked`，在卸载变更锁内再次核验内容指纹，拒绝检查之后发生的修改。
3. 未识别版本、本地改动或迁移失败时保留相应旧包，并在宿主诊断中提供处理提示。未知管理包不自动覆盖，旧商店不会在中心迁移失败后被移除。原配置、私有数据、使用记录与目录缓存均不主动删除。

内嵌声明包只提供可信视图声明与图标，不执行旧包代码。迁移不是通用插件自动升级器，不把同版本号当作覆盖授权，不承诺迁移任意历史或定制版本。

## 验证

无界面测试覆盖身份合并、重复启动、仅商店安装、空目录、保护规则、重启后未知文件保留、配置与私有数据保留，以及检查后文件变化拒绝卸载。继续运行目录、下载、安装、升级和内核回归，并构建前端和桌面二进制。按项目约定不启动真实桌面或浏览器回归，不据此宣称视觉、焦点或原生交互已人工验收。
