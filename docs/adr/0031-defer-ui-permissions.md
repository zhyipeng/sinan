# ADR 0031：回滚并暂缓 UI 权限系统

日期：2026-11-10。状态：已实施。

## 决策

按用户“回滚整套插件权限系统，暂时不做”的指令，撤回 cf70caf 的显式 UI 授权能力，取消随后提出的弹窗授权方向。

移除 UI 权限管理界面、包指纹授权记录读取、用户授权调用门禁、宿主管理 API、CLI 和专用测试；还原原生/核心测试夹具，无需预先授予测试权限。JSON 工具恢复直接使用清单允许的命令和私有数据。

保留桥 2 的声明校验、命令白名单、私有文档命名空间、会话撤销、包完整性、资源与消息预算，以及原生插件安装信任。私有数据占用/清理功能不属于此次回滚范围。

既有 `$ui-permissions` 配置不再读取或用于授权判断；不主动删除或改写用户配置文件。权限系统回到待规划状态，本轮不继续实现弹窗或其他授权流程。

## 验证

仅执行不弹窗的 make test、静态检查和构建；不启动真实桌面、WebView 探测或浏览器交互回归。验证结果见核心能力检查文档。
