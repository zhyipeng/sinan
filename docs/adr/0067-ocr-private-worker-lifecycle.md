# ADR 0067：OCR 插件异步任务与私有 worker 生命周期

状态：本地实现，未发布；完整原生包仅在 macOS arm64 构建并完成无界面验证。

## 决策与原因

官方仓库新增 `tools.ocr`，本阶段通过既有 `clipboard.v1` 读取用户显式触发的一张剪贴板 PNG，在隔离页面展示可编辑结果并复制。识别、任务状态和原生引擎均在插件层，不增加内核 OCR 业务，不扩展公共协议、SDK 或 Wails Bridge。

OCR 不在页面桥的 500 ms 同步调用内完成。插件用现有 `command.execute` 暴露 `start`、`poll`、`cancel`，start 立即返回随机任务 ID；后台异步读取剪贴板后启动 worker。每插件最多一个在途任务/worker，完成结果最多四项、一分钟；PNG 上限 8 MiB/1600 万像素、结果上限 UTF-8 32 KiB。错误、超限不静默截断，不记录图片或识别内容。

页面每秒轮询，5 秒无轮询后由 250 ms 清理周期取消；隐藏/关闭时尝试主动取消，失去桥接后依靠租约。任务 ID 是本插件私有查找句柄，不是新增的宿主会话绑定；不能把这一机制描述为内核提供的即时视图撤销通知。正常识别预算 30 秒。

独立 worker 使用 RapidOCRLite v5.0.0a6 C ABI 和固定 PP-OCRv6 small 权重。前期实验表明释放原生句柄后 RSS 不明显下降，因此每任务运行一个短生命周期进程，结束后退出，而非常驻加载模型。默认 fast-math 构建曾漏行和输出不稳定，构建须追加严格浮点选项；更多编译器、真实样本和 alpha 引擎稳定性仍需验证。

## 父进程退出与回收

当前宿主不保证回收任意插件后代进程。本轮不改变该运行时边界，而在插件私有管道上实现父进程存活约束：

1. 父进程创建 stdin 管道，通过 4 字节大端长度和原始 PNG 发送唯一图片，然后保持写端打开，直到 worker 结束并 Wait。
2. worker 收到完整图片后，另起 Go goroutine 监控 EOF 或额外输入；检测到父端消失即终止整个 worker，包括主 OS 线程还在 C++ 内部运行的情况。传输中断则不进入识别。
3. 后台正常取消/超时用 context 杀掉 worker 并 Wait；SDK 输入结束时取消所有任务并等待回收。后台被强杀时 OS 关闭管道，worker 自行退出，另有 35 秒硬退出兜底。

worker 只产生原生计算线程，不启动后代进程。该 EOF 设计针对插件自己创建、未外传的私有管道，不代表宿主可回收任意第三方插件的任意后代，也不是 OS 沙箱。

图片只在宿主剪贴板 RPC、后台内存及父子管道中传递，不生成临时图片文件；子进程使用明确环境白名单，stdout/stderr 均有界。文件/模型路径来自固定包布局，不接受页面指定路径。

## 平台、SDK 和分发影响

后台和管道机制使用共享 Go 接口，Windows 子进程隐藏控制台；三端后台的无界面测试进入现有 CI，六目标后台编译与静态检查单独输出到非发行目录。

完整原生打包目前显式限定 macOS 本机目标。macOS arm64 已构建；macOS amd64 未构建/运行；Windows 仍需 Unicode 模型路径与 C++ DLL/工具链分发适配，Linux 仍需运行库和目标原生依赖验证，两端构建入口返回明确不可用，不能生成伪兼容包。Linux 的剪贴板沿用宿主 X11/Wayland 区分，截图捕获不在本阶段范围内。

官方打包器对包内 backend 原生辅助程序核验目标头并保留 Unix 执行位，同时检查既有 64 MiB/2048 条目预算。这里不新增 manifest 字段或登记格式；旧发行资产不改写。官方仓库 SDK 快照保持不变，新插件要求宿主已有 `clipboard.v1` 和 UI Bridge 2 文本复制能力。登记仓库没有新增记录或资产。

页面尚不声明主搜索图片匹配：会话图片目前只交付页面，后端无法通过现有接口读取它。不能通过重读当前剪贴板替代用户选中的会话图片。系统截图后复制到剪贴板可作为本版工作流，插件自己的截图选区、文件输入及后端会话图片资源能力留待后续设计。

## 验证边界

已通过官方仓库 104 项前端测试、3 项打包测试及四个插件后台的竞态回归；OCR 覆盖任务、租约、超时、无效图片、输出上限、迟到结果、假 worker 取消及父端关闭。三端 CI 配置已扩展，远端本轮未执行；本机完成六目标后台交叉编译/静态检查，不等于在目标系统运行。

macOS arm64 真实后台/worker 在系统级禁网中，通过模拟宿主 Host API 识别 11 张合成图片，输出与前期严格浮点原生基线一致；验证普通打开不读取剪贴板、单任务限制、非图片拒绝、主动取消及强杀后台后 worker 退出。本轮没有读取系统剪贴板，没有启动桌面、WebView、浏览器或权限窗口。

完整包约 35.59 MiB，ZIP 约 27.80 MiB；辅助程序执行位和原生头校验通过，临时宿主目录检查、安装和静态搜索通过。macOS 原生组件已显式对齐宿主 12.0 最低构建目标并核对 Mach-O，旧系统运行仍未验证；含空格和中文的安装路径下，11 图和后台强杀回收复测通过。用户日常插件目录未修改；未提交权重、发布、登记商店或完成真实 UI/系统剪贴板验收。实现与复现见[官方插件说明](../../../sinan-official-plugins/plugins/ocr/README.md)，本轮摘要见[验证数据](../research/ocr-plugin-validation-results.json)。
